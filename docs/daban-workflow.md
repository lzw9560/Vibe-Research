## 为什么不是 edge 策略

打板赚的是**情绪溢价**的钱（涨停=当天最强，次日惯性溢价；连板=情绪接力），不是企业价值。
打板的 edge 不在"规则化选股"（项目已测 0 存活），而在**人的手艺**——盘感、情绪周期判断、
封单真伪识别、退潮管手。这些不可回测、不可复制成规则。

所以本文档是**手艺执行框架 / checklist**，帮你一致地执行打板手艺，**不保证 edge**。
"赚"全在下面标注为【主观盘感】的那几步；那几步恰恰是不可机械化的。

| 视角 | 最看重 |

## 时序 workflow

每步分 **【客观可执行】**（有阈值/明确动作）和 **【主观盘感】**（靠人判断，不可机械化——edge 恰在这里），
**【红线】** = 绝不做。

### 1. 盘前（9:00 前）— 题材扫描 + 龙头候选 + 情绪周期定位

- **【客观】** 扫昨夜/早盘消息：政策文件、行业事件、龙头动态。列当日可能发酵题材（2-3 个）。
- **【客观】** 看昨日连板梯队：几只连板、最高几板、是否炸板。连板密集=高潮期，断档=冰点/退潮。
- **【主观盘感】** 定情绪周期阶段：冰点 / 发酵 / 高潮 / 退潮。依据：昨日打板次日溢价率（高开多=发酵高潮，核按钮多=退潮）、连板高度趋势。
- **【红线】** 退潮期 → 当日**不打，空仓**（最难做到但最关键）。冰点期 → 极轻仓试错首板。

### 2. 竞价（9:15-9:25）— 看竞价意愿、定候选、辨真假单

- **【客观】** 9:15-9:20 挂单可撤，**不当真**（假单诱多）。
- **【客观】** 9:20 后不可撤单，看：竞价高开幅度（3-7% 偏强）、竞价金额、封单是否持续到 9:25。
- **【客观】** 一字涨停（竞价封死）→ 散户买不到，放弃，别追。
- **【主观盘感】** 辨竞价真假：高开但竞价量极小=诱多；高开 + 竞价量放大 + 9:25 不撤=真强。
- **【红线】** 竞价高开 >8% 但没一字 → 别追（开盘大概率冲高回落套人）。

### 3. 开盘（9:30-10:30）— 打板 / 回封判断、封单质量

- **【客观】** 秒板（9:30-9:31 直拉涨停）：最强但最被量化收割，谨慎。
- **【客观】** 看封单量：封单 > 流通盘 5% 算强（粗参考）。封单 9:20 后才是真。
- **【客观】** 看封板时间：早盘板（9:30-10:30）> 午盘板 > 尾盘板。
- **【主观盘感】** 封单真伪：大单不撤 + 分时不抖 = 真；封单忽大忽小 / 对倒痕迹 = 假。**打板最难的一步，全靠盘感。**
- **【主观盘感】** 回封板识别：首封→炸板→换手→再封。**回封比首封更值得打**（经换手检验）。专打回封是老手主流打法。
- **【客观】** 板块联动：同板块 ≥3 只一起封 = 题材真热，打龙头；孤品板放弃。
- **【红线】** 烂板（盘中多次开板回封）放弃；4 板+高位加速板放弃；无题材孤品板放弃；ST/问题股放弃。

### 4. 盘中（10:30-14:30）— 持有判断、烂板识别、不加仓

- **【客观】** 已封死到午盘 + 封单不撤 = 持有，等次日。
- **【客观】** 换手率参考：<5% 易被砸（筹码没交换），>30% 可能烂板。甜区 8-20%。
- **【主观盘感】** 封单松动迹象：封单持续减少 / 出现大单砸盘 / 同板块跟风板先炸 → 准备次日低开，记笔记。
- **【红线】** **不加仓摊平**（T+1 锁仓，加仓等于加大次日核按钮暴露）。打板一次性进场，不补。

### 5. 尾盘（14:30-15:00）— 卖出处理 / 不打尾盘板

- **【客观】** 尾盘偷袭板（14:30 后才封）→ **不打**（次日溢价通常差，资金没信心早盘封）。
- **【客观】** 已持有且封板松动 → 尾盘不卖（T+1 卖不了），记好次日预案。
- **【红线】** 别为"凑操作"去打尾盘烂板。

### 6. 次日（9:15-10:30）— 竞价定卖点、不及预期止损

- **【客观】** 高开 3-5%+：竞价或开盘卖，落袋。
- **【客观】** 继续涨停（加速板）：持有，盯住，随时准备走（加速到顶就是一字跌停起点）。
- **【客观】** 低开/平开（不及预期）：开盘或反抽走，**不恋战**。"等回本"是打板最大坑。
- **【红线】** **核按钮（一字跌停）**：认亏，不补仓。T+1 当天买当天卖不了，一字跌停想止损都卖不掉——这是打板最致命风险，仓位纪律就是为了扛这个。

### 7. 跨日纪律（每日）

- **【客观】** 单只仓位 ≤20-30%，分散打 3-5 只对冲单只核按钮。
- **【主观盘感】** 退潮期管手：亏钱效应起来（连板断档、打板次日普遍亏）→ **空仓等下一轮发酵**。这是打板赚亏的真正分水岭，纯靠纪律+盘感。
- **【客观】** 每日复盘：打了什么板、封单真伪事后验证、次日溢价、情绪周期判断对不对。手艺是复盘喂出来的。
- **【红线】** 连续亏损 3 天 → 强制停手一周（情绪坏了打板必乱）。

## 怎么用这个 workflow

1. **别当 edge 策略用** — 它不产生统计 edge，只是把打板手艺步骤化。项目测过规则化打板选股 0 存活，"赚"全在【主观盘感】那几步，不可回测。
2. **先模拟盘** — 用 PaperPortfolio 照这个 workflow 跑 30-60 天，看你的【主观盘感】那几步（封单真伪、情绪周期、退潮管手）判断准不准。模拟盘都不赚钱，真盘更别上。
3. **重点盯退潮管手** — 所有打板亏大钱的人，都不是不会打，是退潮期管不住手。这一步做对比任何打板技巧都值钱。

## 附录：术语速查

| 术语 | 含义 |
|---|---|
| 打板 | 涨停瞬间（涨停价）挂单买入，赌次日溢价或继续连板 |
| 封单 | 涨停价上的买盘挂单量；封单大小反映资金强度 |
| 炸板 | 涨停后盘中打开（封单被砸穿） |
| 回封 | 炸板后换手再封；回封 > 首封（经换手检验） |
| 烂板 | 盘中多次开板回封，次日多杀多概率高 |
| 秒板 | 开盘（9:30-9:31）直拉涨停，最强形态 |
| 一字板 | 竞价就封死涨停，全天不开板，散户买不到 |
| 核按钮 | 次日一字跌停，T+1 持仓无法止损 |
| 连板梯队 | 当日各高度连板的股票集合，反映情绪强度 |
| 情绪周期 | 冰点 → 发酵 → 高潮 → 退潮，循环往复 |
| 龙头 | 题材里最先涨停、封单最大、连板最高的票 |
| 跟风 | 题材里跟在龙头后面涨停的票，次日溢价差 |
