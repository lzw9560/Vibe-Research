# backtest-discipline-guard

通用策略回测验证框架。**任何信号在投入真金前必须通过四步验证。**

核心纪律：**没有对照组的胜率 = 确认偏误。** 信号看起来"有效"不等于有 alpha，必须和随机对照组比较且四道门全过。三个看似"有效"的策略加对照组后全部退化到与随机无差异——这是回测的默认失败模式，不是个例。

四步把"看起来有效"翻译成"统计上有效"：**基准率**（分母）→ **信号 IC**（分子）→ **幸存者偏差**（修正项）→ **止损回测**（风险）。缺一不可：只做前两步得到漂亮假象，只做前三步忽略下行风险。

## 四步验证流程

### 第1步：基准率（分母）

> "随机选一只标的，N 日涨>X% 的概率？"

```python
# 任意数据源（akshare/tushare/hithink 等）抽 80 只随机标的 30 日 K线
# P(20日涨>15%)=6.2%  P(涨>10%)=7.5%  P(涨>5%)=12.5%
# 存 <temp>/baseline_stats.json 供后续对比
```

**没有基准率，所有"胜率"都是确认偏误。**

### 第2步：信号 IC（含偏差）

> "有信号 vs 随机标的，收益差异多大？"

```python
# signals = fetch_signal_data(date=DATE)  # 任意信号
# 似然比 = P(涨>X% | 有信号) / P(涨>X% | 无信号)  # 此处是"表面 IC"，下一步才修
```

**>1.5 有效；1.2-1.5 弱；<1.2 无效。** 表面 IC 通过不算数，必须过第 3 步。

### 第3步：幸存者偏差检查（关键！）

> "涨幅发生在信号日之前还是之后？"

```python
# pre_ret = (信号日收盘 - 起点收盘) / 起点收盘
# post_ret = (终点收盘 - 信号日收盘) / 信号日收盘
# |pre_ret|>>|post_ret| → 严重幸存者偏差；真实口径=post_ret（信号日前买不进去）
# 真实口径似然比 = P(post_ret>X% | 有信号) / 基准率
# 信号数据存 <temp>/signal_data_<date>.json，K线缓存 <temp>/<code>_klines.json
```

**最致命陷阱：表面似然比可能虚高一个数量级，真实口径往往回到基准附近甚至低于基准。**

### 第4步：止损回测

> "不同止损线下，策略的真实期望收益？"

```python
# buy_price = 信号日 + N 日收盘价（你能成交的价格）
# 逐日：low<=stop→止损；high>=target→止盈；否则持有到期
# 测试 -5%/-7%/-10%/-15%，找平均收益最高且误杀率可接受的那档
```

**止损必须匹配策略：过紧误杀洗盘，过松单亏吃掉多盈。用 ATR 中位数校准。**

## 示例案例：龙虎榜跟庄验证

> 示例案例数据，非定稿结论。来自特定市场/特定时间窗口，仅供理解四步如何应用。

- 基准率 P(涨>15%)=6.2%；表面 IC 似然比 9.08x（假象，未修正）；真实口径似然比 0.49x（低于基准）；止损回测三档全负期望。
- 子分类：A 组（涨幅适中+小资金+低热度）胜率 59% 探索性；B 组（涨停+大资金+高热度）胜率 19% 陷阱。
- 59% 在样本量约 60 时 z=1.40 p=0.081 统计边缘未显著，扩到大样本后完全不显著，标注"探索性"非定稿依据。

## 关键教训

1. **笼统跟庄无效**——有效子类和陷阱子类混算 = 负期望。**分类是关键。**
2. **幸存者偏差是最大陷阱**——表面 9x 是涨幅发生在信号日之前，你买不进去。
3. **表面 IC 必须修正**——只做前两步下结论 = 用假象做决策。
4. **止损必须匹配策略**——过紧误杀洗盘（某策略 -10% 误杀率 22%），过松单亏吃掉多盈。
5. **没有对照组的胜率 = 确认偏误**——三个策略都"有效"，加对照组后全部不显著。默认失败模式。

## 免责声明

⚠️ 回测基于历史数据，不代表未来表现。本框架提供方法论，案例仅作研究参考，不构成投资建议。样本量 <30 标注"探索性"，不得作为定稿依据。
