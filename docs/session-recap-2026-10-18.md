### 2. 2026年唯一统计显著的alpha

**策略**：小成交额(最低10%) + 当日跌<-3% + 止损-5% + 持有10个交易日

| 指标 | 值 |
|------|-----|
| 日组合 | n=158 mean=+0.99% WR=44% |
| 单只 | n=5517 mean=+1.60% WR=48% |
| t检验 | t=1.961 p_one_sided=0.0258 ✅ |
| vs全市场 | mean-3.56% WR30% → 跑赢4.55个百分点 |

**alpha来源**：小成交额=低关注度=信息效率低 + 跌<-3%=情绪性错杀 + -5%止损=熊市保守

**局限**：median为负(-0.24%)，alpha来自右尾（少数大涨票拉动）；4月+4.61%拉高了整体；样本仅158个交易日。

**代码**：`backend/strategies/low_volume_dip.py` + API `/api/strategy/lvd/scan`

### 理论上的6类前兆

1. **量价配合**：+3~7%强势未封板+量比>2（主力建仓未封板）
2. **尾盘抢筹**：14:30-15:00量价齐升
3. **竞价量比**：9:25异常
4. **大单/资金流**：主力单笔大流入
5. **板块轮动**：同板块已涨停+跟风票次日补涨
6. **龙虎榜游资席位**（但inst_dominant T+1延续已证伪）

### 诚实反思：为什么简单前兆大概率无效

**核心矛盾**：如果简单量价前兆（+5%+量比>2）真能预测涨停，量化基金/游资早已把它吃到消失。A股短端预测竞争激烈，任何简单的日级量价前兆大概率已被市场定价或被主力反向利用（诱多）。

**数据验证的局限**：
- lift 10x看起来高，但命中率只有5-8% → 92-95%满足条件的票不涨停
- 假阳性极高——满足"前日涨>5%+量比>2"的200只票里只有16只涨停
- 无法区分"主力建仓未封板"和"主力出货未封板"——两者前兆特征相同
- 日级数据太粗——真正的建仓痕迹在分钟级/大单/盘口层面

**真存活的前兆可能是什么**：
1. ①复杂组合（量价+题材+资金流+情绪多维交叉）
2. ②非线性（ML模型而非简单阈值）
3. ③高频/分钟级（项目当前数据基础设施不支持）
4. ④小众不可规模化（资金容量小，量化大资金无法参与）

**结论**：简单日级量价前兆大概率lift微弱或被操纵反噬。如果要做涨停预测，需要：
- 分钟级数据（intraday_quote_snapshots只有700只票/24个时间点，不够）
- 大单/资金流数据（当前无来源）
- 题材/板块情绪分析（hot_stock有热度排名但无题材映射）
- 非线性模型（当前只有简单阈值过滤）

**当前能力边界**：项目能在涨停后做战法匹配（打板工作流），但不能在涨停前做有效预测。LVD策略（小成交额+跌<-3%）是2026年唯一统计显著的alpha，但它选的是跌的票不是涨停的票。
