# A 股定律集 — 决策参考知识库

> 收集 A 股市场已知规律/效应，按证据强度分级，标注系统现有覆盖状态。
> 维护规则：新增定律追加到对应分类；验证后更新证据等级。
> 用途：战法匹配、仓位建议、漏斗过滤、日历因子的决策参考知识源。

## 证据等级

| 等级 | 含义 |
|---|---|
| **已验证** | 本系统回测数据支持（标注样本量+结论） |
| **理论充分** | 逻辑自洽 + 学术文献支持，但本系统未回测 |
| **经验共识** | 市场广泛认同，但缺乏严格统计验证 |
| **传说待验** | 可能存在但证据不足或方向存疑 |

## 系统覆盖状态

| 状态 | 含义 |
|---|---|
| **已接入** | 系统已有实现（标注模块） |
| **待接入** | 数据已有但未用于决策 |
| **需新数据** | 需要新数据源才能验证/接入 |
| **不适用** | 与当前策略无关 |

## 一、日历效应

### 1.1 周四逆势涨停效应
- **定律**：周四大盘普跌环境下仍涨停的票，次日延续概率最高
- **证据**：已验证（9 样本，周四信号日胜率 88.9% vs 基准 73%）
- **系统**：待接入（PositionAdvisor 日历因子）
- **注意**：样本量小（9），方向明确但幅度待积累

### 1.2 周五过夜风险
- **定律**：周五信号日涨停 → 次日为周一，周末 gap 风险侵蚀延续动力
- **证据**：已验证（11 样本，周五胜率 63.6% vs 基准 73%）
- **系统**：待接入（PositionAdvisor 周五降仓 ×0.7）

### 1.3 节前缩量效应
- **定律**：节假日前后资金抽离、流动性下降，涨停延续动力不足
- **证据**：已验证（5 样本，节前胜率 60.0% vs 非节前 73.9%）
- **系统**：待接入（节前 3 日降仓 ×0.5，节前最后 1 日不建仓）

### 1.4 五穷六绝七翻身
- **定律**：5 月跌、6 月跌、7 月反弹
- **证据**：经验共识（年度周期性，但近年弱化）
- **系统**：不适用（短线打板策略不依赖月度周期）

### 1.5 春节红包行情
- **定律**：春节前后市场倾向上涨
- **证据**：经验共识
- **系统**：不适用

## 二、涨停板制度效应

### 2.1 一字板最强信号
- **定律**：开盘即封死、全天不打开的涨停，封板意愿最强，次日溢价最高
- **证据**：理论充分 + 回测间接验证（缩量涨停 vr<1.0 胜率 78.6% > 放量 68.8%）
- **系统**：待接入（需识别一字板：开盘价=涨停价 且 全天未开板）
- **注意**：一字板买不到，实战中看的是"能否排队成交"而非"是否该选"

### 2.2 炸板回封 = 弱中带强
- **定律**：涨停后开板再回封，说明抛压被消化，回封后仍有延续
- **证据**：理论充分（match_strategies 有 break_reseal 战法，zt_count 3-5 黄金区 89.5% 命中率）
- **系统**：已接入（STRATEGY_REGISTRY break_reseal，但 60 日无信号——因子缺供）

### 2.3 首板溢价 vs 连板溢价
- **定律**：平均而言首板次日溢价 > 连板次日溢价（首板是"新事件"，连板是"延续"）
- **证据**：经验共识（但方向与系统回测一致——低频次票胜率更高）
- **系统**：待接入（consec_boards 字段大量 None，首板/连板分流后可验证）

### 2.4 尾盘涨停 = 弱信号
- **定律**：14:30 后才封板的涨停，资金偷袭成分大，次日溢价低
- **证据**：理论充分（封板率因子基于封板时间，早封=高分为正向因子 r=+0.18）
- **系统**：已接入（seal_rate 因子 + end_of_day_sneak 战法）

### 2.5 天地板 / 地天板 = 极端反转
- **定律**：涨停→跌停（天地板）或跌停→涨停（地天板）后，次日大概率反向
- **证据**：传说待验（极端事件，样本极少）
- **系统**：不适用（当前系统不做跌停反转策略）

## 三、量价关系

### 3.1 缩量涨停 > 放量涨停
- **定律**：涨停缩量（量比<1）的次日胜率高于放量涨停（量比>1.5）
- **证据**：已验证（74 样本，vr<1.0 胜率 78.6% vs vr>=1.5 胜率 68.8%）
- **系统**：已验证但未接入过滤（R2 不按量比过滤——回测证明不加更优）
- **注意**：缩量可能是一字板（正面），也可能是关注度下降（负面），需区分

### 3.2 天量见天价
- **定律**：极端放量往往是阶段性顶部信号
- **证据**：经验共识
- **系统**：不适用（短线打板不做顶部判断）

### 3.3 换手率黄金区间
- **定律**：换手 5-20% 为健康涨停，>20% 筹码松动，<5% 关注度不足
- **证据**：理论充分（八项标准之一）
- **系统**：已接入（八项标准换手 5-20%，但回测显示换手过滤降低胜率）

### 3.4 量在价先
- **定律**：放量上涨比缩量上涨更可持续
- **证据**：传说待验（与 3.1 矛盾——涨停场景下缩量反而更好）
- **系统**：不适用（涨停场景下此定律方向相反）

## 四、连板梯队效应

### 4.1 连板高度 = 市场情绪温度计
- **定律**：最高连板高度反映市场情绪温度，高度上升=情绪升温
- **证据**：理论充分
- **系统**：已接入（STI ladder 连板梯队，market_emotion.ladder）

### 4.2 龙头断板 = 退潮信号
- **定律**：最高板龙头断板时，中低位连板也受影响，市场进入退潮
- **证据**：经验共识
- **系统**：待接入（需实时监控龙头股断板事件）

### 4.3 板块联动效应
- **定律**：板块龙头涨停会带动板块内其他股
- **证据**：理论充分
- **系统**：已接入（concept_blocks 概念归属 + catalyst 概念联动）

### 4.4 一日游板块
- **定律**：某些板块只热一天，次日退潮，追入即套
- **证据**：经验共识
- **系统**：待接入（需板块热度持续性判断——连续 N 日资金流入才算热）

## 五、资金面效应

### 5.1 主力净流入连续性
- **定律**：主力资金连续净流入的票，趋势延续概率更高
- **证据**：理论充分
- **系统**：已接入（fund_flow main_net_5d，但常因降级源只有 1 天而 missing）

### 5.2 游资接力 = 连板信号
- **定律**：龙虎榜游资席位连续出现 = 接力买入，连板延续概率高
- **证据**：传说待验（回测显示游资净流出组胜率 83.3%——方向相反！）
- **系统**：已接入（fetch_dt_hot_money_relay）但回测不支持作为过滤
- **注意**：游资接力可能是"已经涨完了"的滞后信号

### 5.3 机构净卖出 = 减仓信号
- **定律**：龙虎榜机构净卖出 = 机构在出货
- **证据**：理论充分
- **系统**：已接入（dragon_tiger_inst_net）

### 5.4 北向资金流向
- **定律**：北向净流入 = 外资看好，净流出 = 外资撤离
- **证据**：理论充分（但 2024-08-19 后个股级北向停更）
- **系统**：已接入但数据源缺失（northbound 常为 None）

## 六、情绪周期

### 6.1 情绪四阶段

### 6.2 高潮期特征

### 6.3 退潮期炸板率上升
- **定律**：退潮期特征是炸板率上升、连板断板增多
- **证据**：理论充分
- **系统**：已接入（STI break_rate）

### 6.4 极端反弹
- **定律**：连续冰点后可能出现极端反弹行情
- **证据**：经验共识
- **系统**：已接入（weather_state "极端反弹" + reverse_package 战法）

## 七、板块轮动

### 7.1 板块热度持续性
- **定律**：连续 2-3 日资金流入的板块才有持续性，单日热度可能是一日游
- **证据**：经验共识
- **系统**：待接入（需板块资金流时序数据，当前只有当日快照）

### 7.2 板块轮动节奏

### 7.3 龙头股引领

### 7.4 冷门板块涨停 = 一日游概率高
- **定律**：冷门板块（无持续资金流入）的涨停，次日回落概率高

## 九、打板实战定律

### 9.1 逆势涨停 = 强信号
- **定律**：大盘下跌时仍能涨停的票，背后资金推动力极强
- **证据**：已验证（周四逆势涨停胜率 88.9%）
- **系统**：待接入（需大盘涨跌幅 + 个股涨停的对比）

### 9.2 首板溢价 > 连板溢价（均值）
- **定律**：首板次日平均溢价高于连板次日溢价
- **证据**：经验共识 + 回测间接支持（低频次票胜率 100%）
- **系统**：待接入（首板/连板分流后可验证）

### 9.3 封板时间越早越强
- **定律**：9:25-10:00 封板 > 10:00-14:00 封板 > 14:30 后封板
- **证据**：已验证（seal_rate 因子 r=+0.18，唯一正向因子）
- **系统**：已接入（seal_rate 因子 + 八项标准 10:30 前封板）

### 9.4 封单量越大越强
- **定律**：封单/流通市值比 > 1% = 封板意愿极强
- **证据**：理论充分
- **系统**：已接入（ZTPoolItem seal_amount + seal_to_float_ratio + 八项标准⑥）

### 9.5 开板次数越少越强
- **定律**：涨停后开板 0 次 > 1 次 > 2 次+
- **证据**：理论充分
- **系统**：已接入（ZTPoolItem broken_count + 八项标准⑤）

## 接入优先级建议

### P0 — 数据已有，改动小，预期 alpha 高

1. **周五/节前降仓**（1.2, 1.3）：PositionAdvisor 加日历因子乘数，改 1 个函数
2. **封板率权重提升**（2.4, 9.3）：基因分重构时把 seal_rate 权重从 25% 提到 40%+
3. **连板率降权**（因子回归）：premium 从 40% 降到 10% 或更低（r=0.06 零预测力）
4. **红盘率/频次反转**（因子回归）：低值反而好，可作反向排序因子

### P1 — 需少量新数据，改动中等

5. **首板/连板分流**（2.3, 9.2）：consec_boards 数据补齐后拆分漏斗
6. **板块热度过滤**（7.4）：涨停股 × 板块热度排名，剔除冷门板块
7. **逆势涨停标记**（9.1）：大盘涨跌幅 vs 个股涨停的对比标记

### P2 — 需新数据管道，改动大

8. **板块热度持续性**（7.1, 7.2）：需板块资金流时序数据（连续 N 日）
9. **非涨停战法数据源**（低吸/反包/平台突破）：需全市场扫描能力
10. **一字板识别**（2.1）：需分时数据判断开盘即封死

### 不接入

- 5.4 北向资金（数据源已停更）
- 2.5 天地板/地天板（极端事件，样本不足）
- 1.4/1.5 月度/年度效应（与短线策略无关）
