## 1. 产品定位

### 1.1 核心理念

> **"什么时候不该打"比"什么时候该打"更重要**

打板工作流不是自动交易系统，而是**短线高手的交易决策操作系统**。它把10年打板经验拆解为可复制的标准化流程，在A股T+1规则下，通过**盘前筛选 → 盘中监控 → 盘后复盘**的闭环，帮助交易者系统化执行打板策略，避免情绪化交易。

## 3. 情绪气象站（Sentiment Weather Station）

### 3.1 定位与价值

情绪气象站是打板工作流的**控制中枢**。它通过多维度加权评分模型，将抽象的市场情绪量化为四种可执行的“天气状态”，并据此自动切换允许使用的打板风格，实现“该出手时出手，该收手时收手”的半自动纪律约束。

### 3.2 设计原则

- **STI 为核心**：以 STI（Sentiment Temperature Index）情绪温度作为核心指标（权重 40%），保证判断的连续性和可追溯性。
- **多因子校验**：结合风险指标（20%）、板块持续性（25%）、资金动量（10%）、舆情情绪（5%），避免单一指标误判。
- **天气→风格映射**：每种天气状态明确对应一组允许使用的战法风格，系统自动过滤不符合当前环境的策略。
- **硬性熔断**：内置三条不可逾越的纪律红线（仓位熔断、撤单熔断、次日强制离场），由系统强制执行，避免人性贪婪破坏纪律。

### 3.3 四天气状态定义

| 天气 | 核心判断指标 | 推荐打板风格 | 系统动作 |
|------|------------|------------|---------|
| ⛈️ 暴风雨（退潮期） | 炸板率 > 40%、连板高度跌破 3 板、跌停家数 > 20 家 | 空仓或绝对禁封接力 | 自动锁死买入条件单，仅允许卖出/清仓 |
| ⛅ 阴天（震荡轮动） | 涨停家数 < 50 家、无明显主线、前日龙头次日多低开 | 首板套利（低位挖掘） | 激活首板挖掘模式，禁用连板接力 |
| ☀️ 晴天（主线主升） | 涨停家数 > 80 家、连板高度不断抬升、赚钱效应在主线 | 连板接力（高位数板） | 激活连板接力模式，禁用首板挖掘 |
| 🌪️ 极端反弹（冰点反转） | 市场经历大跌后，某大题材集体爆发、跌停集体打开 | 弱转强板 / 情绪反包板 | 激活弱转强模式，禁用其他风格 |

### 3.4 多因子加权评分模型

```
天气评分 = STI情绪温度 × 40%
        + 风险指标   × 20%
        + 板块持续性 × 25%
        + 资金动量   × 10%
        + 舆情情绪   × 5%
```

**各维度数据源与计算方式**：

- **STI 情绪温度（40%）**：直接复用现有 `limitup_sti/service.py` 的 8 维度加权得分（涨停家数、跌停家数、封板率、涨跌比、晋级率、昨日涨停表现、连板高度）。
- **风险指标（20%）**：炸板率、跌停家数、大盘 5 分钟急跌次数、北向资金净流出额。
- **板块持续性（25%）**：主线板块连续涨停天数、板块内涨停家数占比、板块资金连续净流入天数。
- **资金动量（10%）**：龙虎榜机构净买入额、大单净流入占比、融资余额变化。
- **舆情情绪（5%）**：东方财富股吧热度、涨停股评论情感得分、大V看多看空比例。

**天气判定阈值**（可调）：

| 天气 | 评分区间 | 附加条件 |
|------|---------|---------|
| ⛈️ 暴风雨 | < 35 | 且炸板率 > 40% |
| ⛅ 阴天 | 35 - 55 | 且涨停家数 < 50 |
| ☀️ 晴天 | 55 - 75 | 且涨停家数 > 80 |
| 🌪️ 极端反弹 | > 75 | 且前日跌停数 > 15 |

### 3.5 半自动工作流（5 步闭环）

```
[步骤 1] 盘前数据扫描
    ↓
[步骤 2] 自动计算情绪天气 ──→ 自动下发【今日允许打板风格指令】
    ↓
[步骤 3] 触发对应选股公式池 ──→ 自动将符合风格的标的加入【临盘监控池】
    ↓
[步骤 4] 盘中分时触发预警 ──→ 系统弹出提示、自动填好涨停价、数量（人工一键确认）
    ↓
[步骤 5] 次日自动执行断板流 ──→ 监控竞价，不符合预期自动挂单单清仓
```

**关键设计**：系统负责“筛选 + 预警 + 条件单准备”，人工负责“最终确认 + 下单执行”。既保证纪律，又保留交易者的临盘决策权。

### 3.6 三大风格配置

#### 风格 A：连板接力模式（晴天 / 主升浪）

- **适用天气**：☀️ 晴天
- **核心逻辑**：强者恒强，追逐市场的最高板、妖股。
- **半自动过滤规则**：
  1. 必须是 2 连板以上的股票。
  2. 行业属性必须属于当日成交额前三的“主线板块”。
- **条件单设置**：
  - 触发条件：价格 ≥ 涨停价 - 0.02 元，且五档卖盘的卖一、卖二单量急剧萎缩（爆量突破）。
  - 执行动作：系统弹窗提示，人工确认后以涨停价扫货。

#### 风格 B：首板挖掘模式（阴天 / 轮动市）

- **适用天气**：⛅ 阴天
- **核心逻辑**：高位连板容易吃面，只打低位第一个涨停板，赚次日溢价就跑。
- **半自动过滤规则**：
  1. 过去 20 个交易日内未出现连板。
  2. 属于当日异动拉升、有突发利好催化的新面孔。
- **条件单设置**：
  - 触发条件：分时图大单点火（单笔成交量超过过去 5 分钟均量的 5 倍以上），涨幅在 7.5% ~ 9% 之间。
  - 执行动作：加入急速雷达监控，自动计算封板所需的买入金额。

#### 风格 C：弱转强 / 反包板模式（极端反弹 / 冰点期结束）

- **适用天气**：🌪️ 极端反弹
- **核心逻辑**：前一日表现很弱（如炸板、大跌），次日突然超级高开，完成情绪反转。
- **半自动过滤规则**：
  1. 昨日留有长上影线（炸板）或昨日跌停。
  2. 今日集合竞价超预期高开 3% 以上，且竞价成交量超过昨日前 5 分钟总和。
- **条件单设置**：
  - 触发条件：开盘 3 分钟内，股价迅速冲过昨日最高价。
  - 执行动作：触发“弱转强”预警，通知交易员准备在封板瞬间切入。

### 3.7 硬性熔断闭环（3 条铁律）

| 熔断类型 | 触发条件 | 系统动作 | 人工干预 |
|---------|---------|---------|---------|
| 总仓位熔断 | 情绪气象站判定为“暴风雨” | 自动锁死交易权限，禁止下发任何买入条件单 | 仅可执行卖出/清仓 |
| 撤单熔断（防钓鱼） | 排板时五档盘口封单金额跌破 3000 万，或撤单量/封单量 > 20% | 自动执行撤单，无需人工确认 | 无 |
| 次日强制离场 | 次日 09:25 竞价结束，股票未高开（< 0%）或开盘 5 分钟内无法站稳均线 | 自动生成市价卖出单 | 交易员只需按下“确定”完成止损 |

### 3.8 与现有系统的集成

- **STI 引擎复用**：直接调用 `/api/market/sti/latest` 和 `/api/market/sti/timeline` 获取情绪温度数据。
- **情绪周期复用**：复用 `SentimentAnalyzer` 的情绪周期计算结果（冰点→启动→发酵→高潮→退潮）。
- **战法系统扩展**：在现有 8 大战法基础上，增加“天气→风格”映射层，自动过滤不符合当前天气的战法。
- **仓位管理扩展**：在 `PositionAdvisor` 中增加天气状态作为仓位计算的额外约束条件。

## 4. 盘前工作流 (08:00-09:30)

### 3.1 流程时序

```
08:00  系统启动，加载配置
08:05  获取昨日涨停板数据 + 龙虎榜
08:10  资金流向分析（板块净流入/流出）
08:15  情绪周期计算
08:20  候选池筛选（八项标准过滤）
08:25  战法匹配（8大战法自动匹配）
08:30  生成盘前报告 + 仓位建议
08:35  飞书推送（盘前 briefing）
09:15  竞价监控启动（候选池实时监控）
09:25  竞价确认（最终买入清单）
```

### 3.2 核心模块

#### 3.2.1 候选池筛选器 (CandidatePoolFilter)

**职责**: 从全市场涨停板中筛选出符合"八项标准"的候选标的

#### 3.2.3 仓位建议引擎 (PositionAdvisor)

**职责**: 基于情绪周期 + 个股置信度，给出科学仓位建议

**仓位计算公式**:
```
基础仓位 = f(情绪周期)
  - 冰点期: 0-10%
  - 启动期: 10-20%
  - 发酵期: 20-50%
  - 高潮期: 10-20%
  - 退潮期: 0%

置信度乘数 = f(个股评分)
  - 高置信度(≥80分): 1.0x
  - 中置信度(65-79分): 0.6x
  - 低置信度(60-64分): 0.3x

战法乘数 = f(战法胜率)
  - 高胜率战法(≥70%): 1.2x
  - 中胜率战法(60-69%): 1.0x
  - 低胜率战法(<60%): 0.8x

最终仓位 = 基础仓位 × 置信度乘数 × 战法乘数
```

**风险约束**:
- 单票最大仓位 ≤ 30%
- 同板块合计 ≤ 50%
- 总持仓数 ≤ 5只
- 当日新建仓总仓位 ≤ 80%（保留20%现金应对机会）

### 5.2 核心模块

#### 5.2.1 自动结算引擎 (AutoSettlementEngine)

**职责**: 自动结算前日推荐，计算实际收益率

**结算逻辑**:
```python
class AutoSettlementEngine:
    def settle(self, recommendation: PositionRecommendation) -> SettlementResult:
        """
        结算单笔推荐
        
        买入价: 次日开盘价（默认）或 推荐入场价区间中值
        卖出价: 次日收盘价（T+1规则）
        收益率 = (卖出价 - 买入价) / 买入价 * 100
        """
        # 1. 获取次日实际行情
        next_day_data = self._get_next_day_data(recommendation.code)
        
        # 2. 计算买入价（开盘价或推荐价）
        buy_price = self._resolve_buy_price(recommendation, next_day_data)
        
        # 3. 计算卖出价（收盘价）
        sell_price = next_day_data.close_price
        
        # 4. 计算收益率
        return_pct = (sell_price - buy_price) / buy_price * 100
        
        # 5. 判定胜负
        won = return_pct > 0
        
        # 6. 更新推荐日志
        self._update_recommendation_log(recommendation, buy_price, sell_price, return_pct)
        
        return SettlementResult(
            code=recommendation.code,
            name=recommendation.name,
            buy_price=buy_price,
            sell_price=sell_price,
            return_pct=return_pct,
            won=won,
            hold_days=1,
        )
```

**结算规则**:
- 次日开盘价 ≤ 推荐入场价区间下限 → 以开盘价买入（实际成交）
- 次日开盘价 > 推荐入场价区间上限 → 放弃买入（无法接受高价）
- 次日一字板跌停 → 以跌停价卖出（极端情况）

## 6. 战法系统

### 6.1 8大经典战法

#### 6.1.1 二板定龙战法

**类型**: 连板接力 | **胜率基准**: 70%

**核心逻辑**: 首板确认龙头地位，二板高开确认资金认可，接力买入

**条件**:
1. 首板评分≥70分
2. 二板高开3%以上
3. 前日换手率5%-15%（适中）
4. 非一字板接力（有换手才有接力空间）

**买入信号**:
- 竞价高开3%-7%，买一量≥卖一量2倍
- 或 开盘后30分钟内封板

**止损**: 开盘价下方3%
**止盈**: 前高压力位或+15%

#### 6.1.2 弱转强反包战法

**类型**: 分歧转一致 | **胜率基准**: 75%

**核心逻辑**: 前日长上影/高开低走显示分歧，当日分时弱转强确认资金回流

**条件**:
1. 前日收长上影或高开低走（上影线≥实体2倍）
2. 当日分时弱转强（早盘下跌后回升，突破分时均线）
3. 上穿分时均线且站稳10分钟
4. 板块仍有热度支撑

**买入信号**:
- 分时线突破均价线，成交量放大2倍
- 突破后10分钟内不回落

**止损**: 分时均线下方3%
**止盈**: +10%或前高

#### 6.1.3 板块龙头接力战法

**类型**: 龙头战法 | **胜率基准**: 65%

**核心逻辑**: 板块内最早封板的标的，享受板块情绪溢价

**条件**:
1. 板块内最早封板的标的（前3只）
2. 板块涨停家数≥3只
3. 流通市值30-200亿
4. 板块题材有持续性逻辑（政策/事件驱动）

**买入信号**:
- 板块第3只涨停确认后，龙头仍有封板动能
- 或 次日高开3%-5%，竞价强势

**止损**: 板块龙头炸板
**止盈**: 板块涨停数<3只或情绪退潮

#### 6.1.4 大基金追踪战法

**类型**: 资金跟随 | **胜率基准**: 60%

**核心逻辑**: 机构资金持续流入的板块，龙头股享受资金溢价

**条件**:
1. 板块连续3日资金净流入
2. 龙虎榜有机构席位净买入
3. 流通市值>100亿（机构偏好）
4. 避开游资主导的小盘标的

**买入信号**:
- 龙虎榜发布后次日，高开2%-5%
- 或 盘中放量突破前高

**止损**: 龙虎榜显示机构净卖出
**止盈**: 资金流向转负

#### 6.1.5 首板突破战法

**类型**: 低位首板 | **胜率基准**: 58%

**核心逻辑**: 历史低位突破，打开上涨空间

**条件**:
1. 股价处于历史低位区间（60日低点附近）
2. 突破60日/120日均线
3. 涨停成交量放大2倍以上
4. 有业绩预增或利好公告支撑

**买入信号**:
- 突破均线后回踩确认
- 或 次日高开2%-4%

**止损**: 跌破突破日低点
**止盈**: +20%或前高压力位

#### 6.1.6 地天板反核战法

**类型**: 极端反转 | **胜率基准**: 55%

**核心逻辑**: 前日跌停显示恐慌，当日地天板显示资金反核

**条件**:
1. 前日跌停或接近跌停
2. 当日地天板（跌停→涨停）
3. 板块情绪修复（板块内多只反弹）
4. 成交量放大3倍以上

**买入信号**:
- 地天板确认后，次日高开2%-4%
- 或 盘中回踩地天板低点不破

**止损**: 跌破地天板低点
**止盈**: +15%或前高

#### 6.1.7 一字板排板战法

**类型**: 筹码锁定 | **胜率基准**: 65%

**核心逻辑**: 一字板筹码高度锁定，次日溢价高

**条件**:
1. 开盘即封板（一字板）
2. 换手率<1%
3. 封单金额>流通市值5%
4. 有重大利好支撑（政策/订单/业绩）

**买入信号**:
- 次日开盘价买入（排队成交）
- 或 盘中开板瞬间买入

**止损**: 开盘价下方5%（一字板开板即弱）
**止盈**: +10%或开板即卖

#### 6.1.8 烂板回封战法

**类型**: 分歧转一致 | **胜率基准**: 60%

**核心逻辑**: 开板多次显示分歧，回封显示资金最终一致

**条件**:
1. 开板≥2次
2. 3分钟内回封
3. 回封后封单金额回升
4. 板块仍有热度

**买入信号**:
- 回封确认后，次日高开2%-4%
- 或 盘中回踩回封价不破

**止损**: 跌破回封价
**止盈**: +10%或前高

### 6.2 战法匹配逻辑

```python
class StrategyMatcher:
    def match(self, stock: SealPlateStock, context: MarketContext) -> list[StrategyMatch]:
        """
        对单只股票匹配所有适用战法
        
        匹配逻辑:
        1. 检查每项战法的硬性条件
        2. 计算匹配度得分
        3. 返回匹配度>60%的战法列表
        """
        matches = []
        for strategy in self.STRATEGIES.values():
            score = self._calculate_match_score(stock, strategy, context)
            if score >= 0.6:
                matches.append(StrategyMatch(
                    strategy_name=strategy["name"],
                    match_score=score,
                    confidence=self._score_to_confidence(score),
                    entry_price=self._calc_entry_price(stock, strategy),
                    stop_loss=self._calc_stop_loss(stock, strategy),
                    take_profit=self._calc_take_profit(stock, strategy),
                ))
        return sorted(matches, key=lambda x: x.match_score, reverse=True)
```

### 7.2 事前控制（盘前）

| 控制项 | 规则 | 目的 |
|--------|------|------|
| 八项标准过滤 | ≥3项未通过直接淘汰 | 避免低质量标的 |
| 战法胜率校验 | 历史胜率<50%的战法降级 | 避免低胜率策略 |
| 仓位上限 | 单票≤30%，同板块≤50%，总持仓≤5只 | 分散风险 |
| 情绪周期适配 | 退潮期总仓位≤20% | 避免逆势操作 |

### 7.3 事中控制（盘中）

| 控制项 | 规则 | 响应 |
|--------|------|------|
| 炸板预警 | 封单减少>30% | 黄色预警，准备减仓 |
| 炸板预警 | 3分钟未回封 | 红色预警，建议清仓 |
| 大盘风控 | 5分钟急跌>0.5% | 建议减仓至50% |
| 情绪风控 | 炸板率>40% | 停止新建仓 |

### 7.4 事后控制（盘后）

| 控制项 | 规则 | 目的 |
|--------|------|------|
| 自动结算 | T+1日收盘自动结算 | 客观评估推荐质量 |
| 胜率统计 | 滚动10笔胜率<30% → 降仓位 | 动态风险调整 |
| 策略优化 | 胜率<50%的战法自动降权 | 持续改进 |
| 风险复盘 | 每周风险事件分析 | 经验沉淀 |
