# Vibe-Research 前端 UI 优化方案

> 目标：简洁、易用、交互顺畅、避免冲突、减少重复、功能归类清晰、有连续性和逻辑性。

---

## 一、现状诊断

### 1.1 导航过载（核心问题）
- **侧边栏 4 个大组** + **顶部 Tab 栏** + **二级 Tab** + **面包屑** = 最多 4 层导航同时出现
- "打板策略" 组塞了 **10 个 Tab**，信息密度过高
- 部分页面（如 `/limitup/*`、`/recommendation`、`/strategy-signals`）在侧边栏和顶部 Tab 中**重复出现**
- 移动端使用 Drawer + 遮罩，功能完整但缺少手势优化

### 1.2 视觉层级混乱
- 所有内容块都使用相同的 `GlassCard`，**主次不分**
- 标题、指标、表格的视觉权重接近，用户难以快速定位重点
- 颜色系统虽统一（暖橙主色 + 红涨绿跌），但**强调色使用过于频繁**，导致重点不突出

### 1.3 信息架构问题
- `DailyReview` 一页塞入 7+ 个大区块，纵向滚动过长
- 表格列过多（如龙虎榜、资金流向），在移动端几乎不可读
- 空状态、加载状态、错误状态的呈现方式不统一

### 1.4 交互细节缺失
- 表格行缺少 hover 反馈
- 按钮的 loading/disabled 状态不统一
- 缺少骨架屏（Skeleton）过渡
- 移动端表格无替代方案

---

## 二、优化原则

| 原则 | 说明 |
|------|------|
| **单一导航源** | 同一层级只保留一种主导航形式，避免侧边栏 + 顶栏双重导航 |
| **渐进式披露** | 默认展示核心指标，次要信息折叠或置于次级 Tab |
| **视觉权重分层** | 主卡片 > 次卡片 > 表格 > 辅助信息，通过边框、背景、阴影区分 |
| **一致性优先** | 同类组件统一交互模式和视觉样式 |
| **移动端优先** | 表格在移动端改为卡片列表，触控目标 ≥ 44px |

## 三、导航重构方案

### 3.1 侧边栏精简

```
市场概览 (Activity)
  ├── 每日复盘
  ├── 情绪气象
  ├── 资讯雷达
  ├── 板块中心
  └── 行业排行

个股分析 (Search)
  ├── 个股数据
  ├── 自选股
  └── 深度分析 (入口，实际跳转需输入代码)

投资管理 (Wallet)
  ├── 我的持仓
  ├── 研究记录
  └── 我的研报

打板策略 (Flame)
  ├── 打板工作流
  ├── 基因选股
  ├── 竞价预案
  ├── 席位引擎
  └── 更多 ▼
        ├── 推荐关注
        ├── 战法信号
        ├── 简化回测
        ├── 性能监控
        ├── 系统健康
        └── 接入 AI
```

**改动点：**
- 将 "推荐关注"、"战法信号"、"简化回测"、"性能监控"、"系统健康"、"接入 AI" 归入 **"更多" 子菜单**
- 侧边栏默认展开当前组，其他组折叠（减少视觉噪音）
- 移除顶部 Tab 栏（与侧边栏重复），改为**仅在移动端显示顶部 Tab**

### 3.2 顶部 Tab 栏（仅移动端）
- 移动端保留顶部 Tab，但**只显示当前组的 Tab**，不跨组
- 增加**滑动指示器**，明确当前所在位置

### 3.3 二级 Tab 统一
- 所有二级 Tab 统一使用**胶囊样式**（`rounded-full` + `bg-muted/30`）
- 当前选中项使用 `bg-primary/15 text-primary`
- 位置统一放在 `PageHeader` 下方，与内容紧贴

## 四、视觉层级系统

### 4.1 卡片层级

| 层级 | 样式 | 用途 |
|------|------|------|
| **Primary** | `glass-glow` + 主色边框 | 核心指标卡（如大盘指数、STI 温度） |
| **Secondary** | 标准 `glass` | 常规数据区块（如市场情绪、板块资金） |
| **Tertiary** | `bg-muted/20` + 无边框 | 辅助信息、列表项 |
| **Embedded** | `bg-muted/15` + 圆角 | 卡片内部的子区块 |

### 4.2 标题系统

```
PageHeader (h1)        → 页面主标题 + 副标题 + 操作按钮
SectionHeader (h2)     → 区块标题 + 图标 + 辅助说明
SubHeader (h3)         → 卡片内部标题
Label (h4)             → 字段标签、指标名称
```

**统一规则：**
- `SectionHeader` 使用 `text-sm font-semibold text-muted-foreground` + 左侧 3px 主色竖线
- 辅助说明使用 `text-[11px] text-muted-foreground/50`

### 4.3 指标卡统一

创建 `MetricCard` 组件，统一所有页面的指标展示：

```tsx
<MetricCard
  label="涨停"
  value="42"
  unit="家"
  trend="+12%"
  trendUp={true}
  hint="较昨日"
/>
```

**样式：**
- 默认：`rounded-lg bg-muted/25 p-3`
- 主指标：`text-lg font-bold font-mono`
- 趋势：`text-xs text-danger` / `text-success`
- 辅助：`text-[11px] text-muted-foreground/60`

## 五、页面级优化

### 5.1 DailyReview（每日复盘）

**问题：** 7 个区块纵向堆叠，滚动过长，重点不突出

**方案：**
```
[PageHeader]
[大盘指数 - 4 列网格] ← Primary 卡片
[全球市场 - 5 列网格] ← Secondary 卡片
[STI 温度 + 时间线] ← 并排布局（桌面端）
[关注股票 - 可折叠] ← 默认折叠，用户主动展开
[市场情绪 + 短线情绪] ← 并排布局（桌面端）
[全市场成交额 TOP20] ← 表格，默认显示 10 条，可展开
[板块资金趋势榜] ← 双列布局（流入/流出）
[复盘报告] ← 独立区块，带日期选择器
```

**关键改动：**
- 使用 **CSS Grid** 实现响应式并排布局
- "关注股票" 默认折叠，减少首屏长度
- 表格默认截断，提供 "展开全部" 按钮

### 5.2 StockDeep（个股深度）

**问题：** 4 个 Tab 内容差异大，但 Tab 样式与页面其他 Tab 不统一

**方案：**
- Tab 样式统一为胶囊式
- "基因" Tab 的因子条形图增加**动画过渡**
- "资金" Tab 的龙虎榜席位信息改为**卡片列表**（移动端更友好）
- "AI" Tab 增加**加载骨架屏**

### 5.3 数据表格优化

**问题：** 列过多，移动端不可读；缺少视觉层次

**方案：**
1. **桌面端：**
   - 表头固定（`sticky top-0`）
   - 斑马纹背景（`nth-child(even)`）
   - 行 hover 高亮
   - 关键列（名称、涨跌幅）加粗

2. **移动端：**
   - 表格改为**卡片列表**，每行一个卡片
   - 或使用**横向滚动** + 固定首列

3. **通用：**
   - 创建 `DataTable` 组件，统一分页、排序、加载状态
   - 支持 `compact` / `comfortable` 两种密度

## 六、组件标准化

### 6.1 新建/统一组件清单

| 组件 | 用途 | 优先级 |
|------|------|--------|
| `SectionHeader` | 统一区块标题 | 高 |
| `MetricCard` | 统一指标展示 | 高 |
| `DataTable` | 统一表格样式 | 高 |
| `EmptyState` | 统一空状态 | 中 |
| `LoadingSkeleton` | 统一加载态 | 中 |
| `TabBar` | 统一 Tab 样式 | 高 |
| `Badge` | 统一标签/状态 | 中 |

### 6.2 状态统一

```tsx
// 统一空状态
<EmptyState
  icon={<BarChart3 className="h-8 w-8 text-muted-foreground/40" />}
  title="暂无数据"
  description="可能是非交易时段或数据源暂时不可用"
  action={<Button onClick={retry}>刷新</Button>}
/>

// 统一加载状态
<LoadingSkeleton rows={5} columns={4} />
```

## 七、移动端优化

### 7.1 断点策略
- `sm`: 640px（手机横屏）
- `md`: 768px（平板）
- `lg`: 1024px（桌面）

### 7.2 关键改动
1. **侧边栏**：移动端为 Drawer，桌面端为固定侧边栏
2. **表格**：`< 768px` 时自动切换为卡片列表
3. **网格**：指标卡从 4 列 → 2 列 → 1 列
4. **触控目标**：所有按钮 ≥ 44×44px
5. **字体**：移动端最小字号 12px，避免过小

## 十、设计参考

- **Glassmorphism**：保持现有玻璃质感，但减少过度使用（非核心卡片去掉 `backdrop-filter`）
- **颜色**：主色 `#F35D2B`（暖橙），成功 `#22c55e`（绿），危险 `#ef4444`（红）
- **字体**：Inter（正文）+ JetBrains Mono（数字）
- **圆角**：`rounded-lg`（8px）用于卡片，`rounded-full` 用于标签和按钮
- **阴影**：核心卡片使用 `shadow-lg` + `shadow-primary/10`
