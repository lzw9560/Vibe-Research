> 状态：已通过（2026-07-28 签字）｜P1 已实现（2026-07-28，见 验收报告.md）｜作者：Claude ｜日期：2026-07-28

## 0. 摘要

本轮（P1）把短线分析诊断框架统一进**盘前候选池（分阶段漏斗式筛选）与个股诊断卡**。候选池按漏斗多轮筛选——每轮在上轮结果上叠加过滤，从宽源到定稿；阈值随市场情绪温度自适应。个股诊断卡一屏呈现六类指标 + 活跃度档位 + 企稳信号命中。使"候选"环节先跑在统一诊断口径上，为 P2/P3/P4 复用打基础。

**P1 不做**：盘中实时信号、盘后结算复盘、企稳触发器、AI 复盘、参考价位输出（隔离为独立"研究模式"spec）。

---

## 1. 背景与目标

- 现有打板工作流候选、信号、结算各用一套口径；此前对 6 标的的短线分析证明"六类指标 → 活跃度档位 → 企稳信号"诊断口径有判断价值。
- **P1 目标**：候选池漏斗各轮与诊断卡使用**同一套六类指标定义与活跃度分档规则**，口径统一、可复现；阈值随情绪自适应。
- **重构成功度量**：同一只股票在候选池各轮、诊断卡两处看到的指标定义、分档规则、取数口径完全一致；任一标签可由公开数据 + 既定规则复算（可用 `~/tools/financial_rigor.py` 核对）。

---

## 2. 合规边界

- **严守红线**：P1 全流程只输出客观事实与可复现分档，**不输出买卖方向/时机/排名/收益承诺/主观评分**。
- **位置判断**：系统只出客观分档（规则可复现），"回撤/出货/健康"等方向结论交用户 AI，系统不输出结论词。
- **涨停四池原始个股名**仅用于聚合成无个股名的情绪指标，或作为客观榜单呈现。
- **参考价位（入场/止损/止盈）不在 P1、不在主流程**：隔离为独立"研究模式"特性，另立 spec（S00x）单独签字。P1 不涉及。

---

## 3. 用户角色

- **主用户**：个人短线交易者（自托管本系统、用自己 AI 分析）。

---

## 4. 用户故事（P1）

### 候选池漏斗
- **US1 分阶段漏斗候选池**：作为短线交易者，我想候选池按多轮漏斗生成——每轮在上轮结果上叠加过滤（盘后宽源 → 次轮活跃度/资金流 → 盘前竞价/公告定稿），以便分层收敛、每层可检视。
- **US2 各轮来源与阈值可配**：我想开关每轮的筛选源与阈值；阈值可随市场情绪温度自适应（自动/建议/手动三模式）。
- **US3 自选与手动并入**：自选股/手动粘贴的代码作为独立通道并入漏斗（可作为某一轮的输入或并行通道）。
- **US4 每层可检视**：我想看到每轮漏斗的输入数、输出数、被过滤掉的标的与过滤原因，便于调参。

### 诊断卡
- **US5 个股诊断卡**：对候选池任一标的，一屏看全六类短线指标 + 活跃度档位 + 企稳信号命中，且口径与候选池排序处一致。
- **US6 数据缺失透明**：任一指标取不到时标"未取得"+原因，不臆造、不补全、不静默。
- **US7 可复现**：任一标签/分档标明取数时点与所用规则（含当时情绪档位与对应阈值），我能复算核对。

## 5. 短线信号维度与自适应阈值（P1 诊断框架）

### 5.1 六类指标
| 维度 | 指标 |
|---|---|
| 量价 | 换手率 / 量比 / 成交额 / 量价配合（突破放量、高位放量） |
| 情绪梯队 | 连板高度 / 封板率 / 炸板率 / 晋级率 / 涨停家数 / 昨涨停今表现 |
| 资金流 | 主力净流入 / 5日累计 / 龙虎榜席位（机构 vs 游资）/ 北向 |
| 催化剂 | 公告（预增/重组/回购）/ 题材发酵 / 板块联动 |
| 技术位（辅助） | 均线 / BOLL / MACD |

补充参考信号（客观呈现）：封单金额与封单/流通市值比、竞价表现、板块资金净流入与轮动、筹码分布、分时量比突变、大宗交易折溢价+股东户数变化。

### 5.2 活跃度分档（基数 + 情绪自适应）
**基数阈值**（取自短线分析）：换手 冷<8% / 活跃 8-20% / 热>20%；量比 2 倍=放量分界；成交额>10 亿=有资金容量；振幅>8%=高波动。

**情绪自适应三模式**（对接项目 STI/情绪天气）：
- **自动**：系统按当日情绪温度（如暴风雨/晴天）自动收紧或放宽阈值（如暴风雨期换手下限提至 12%）。
- **建议（默认）**：系统按情绪给出建议阈值并显示依据，用户一键接受或手调。
- **手动**：用户完全自定阈值。

> 自适应只调"档位边界"，不引入方向判断；情绪档位本身是客观计算（STI）。

## 6. 候选池漏斗设计（已确认）

| 轮次 | 时点 | 输入 | 叠加过滤 | 产出 |
|---|---|---|---|---|
| R1 宽源 | T-1 盘后 | 全市场 | 涨停基因得分 + 连板梯队（含炸板/昨涨停今表现） | 宽候选池 A |
| R2 收敛 | T-1 盘后/R2 | A | 全市场活跃度（换手/量比/成交额）+ 资金流（主力净流/龙虎榜机构） | B |
| R3 定稿 | T 日 9:00 前 | B | 集合竞价异动 + 公告催化当日 + 板块联动跟风 | 定稿候选池 C |
| 并行 | 任意 | 自选/手动粘贴 | （并入 R2 或独立通道） | — |

每轮输出为下轮输入（漏斗）；任一层为空则下游无输入并提示。

## 7. 验收标准（P1）

- **AC1**：候选池按漏斗多轮生成，每轮在上轮结果上叠加过滤，输出 A→B→C，每层可检视输入/输出数与过滤原因。
- **AC2**：各轮来源可开关、阈值可配；阈值支持自动/建议/手动三模式，默认建议模式。
- **AC3**：自选/手动粘贴作为独立通道并入漏斗。
- **AC4**：诊断卡一屏呈现六类指标 + 活跃度档位 + 企稳信号命中，且与候选池各轮**口径完全一致**。
- **AC5**：任一标签/分档可展示取数时点、所用规则与当时情绪档位/阈值，可用 `financial_rigor.py` 复算。
- **AC6**：指标取不到时显示"未取得"+原因，不补全、不臆造。
- **AC7**：全市场扫描（R1 宽源）走 9:00 前一次性、批次 50、复用路由缓存、优先不封 IP 的行情层，不触发东财封 IP。
  > 澄清（2026-07-29）：R1 的"全市场"输入经涨停四池/基因筛选聚合（B1/B2，非裸 quote 扫描）；批次 50 的全市场行情 quote 扫描实际发生在 R2 活跃度采集（B3）。AC7 的批次 50 + em_get 限流约束对应 B3，R1 仍为宽源但不直接做批量 quote 拉取。
- **AC8**：ST/*ST/退市整理、新股次新在漏斗中剔除或单独标注，不与正常股混排。
- **AC9**：任一漏斗层为空时提示"该层无符合标的"，下游无输入不报错。
- **AC10**：位置判断不输出方向结论词，只出客观分档。

## 8. 边界情况（P1 相关）

| 场景 | 处理 |
|---|---|
| 停牌/临停 | 停牌标的剔除出漏斗；复牌首日单独标注 |
| ST/*ST/退市整理 | 剔除或单独标注，涨跌停按 5% 识别 |
| 新股/次新 | 单独标注，不参与连板梯队统计 |
| 数据源缺失 | 对应指标标"未取得"+原因，该维度分档降级，不补全 |
| 龙虎榜数据滞后 | 标"待披露"，次日补回，不臆测席位 |
| 北向不可得 | 资金流北向项标"未取得"，其余正常 |
| 全市场扫描触发限流 | 走批次+缓存+腾讯行情层优先，超限时部分标"未取得"而非失败 |
| 漏斗某层为空 | 提示"无符合标的"，下游无输入 |
| 情绪温度异常/缺失 | 自适应降级为基数阈值，并标"情绪档未取得" |
| 极端估值标的 | 诊断卡对估值异常（PE>200 或亏损）加显著风险标 |

> 熔断、涨停潮/跌停潮、一字板、尾盘异动、炸板预警属 P2/P3。

## 9. 非目标（P1）

- 不做盘中实时信号与推送（P2）、盘后结算与 AI 复盘（P3）、企稳触发器（P4）。
- 不输出参考价位（研究模式 S00x）。
- 不接入券商、不下单。
- 不改数据层与通知系统内部实现，复用现有能力。
- 不迁移/改动现有状态机持久化（属后续阶段）。

---

## 10. 决议（已签字 2026-07-28）

1. ✅ **漏斗轮次划分**：采用 §6 草案——R1(盘后宽源：涨停基因+连板梯队) → R2(活跃度+资金流) → R3(盘前竞价+公告) 三轮 + 自选/手动并行。
2. ✅ **自适应阈值默认模式**：默认"建议模式"（系统按情绪温度给建议、用户一键接受或手调），自动/手动可切。
3. ✅ **基数阈值**：换手 8%/20%、量比 2 倍、成交额 10 亿、振幅 8% 固化为基数；自适应只在此基数上调整档位边界（如暴风雨期换手下限提至 12%），不引入方向判断。
4. ✅ **研究模式 spec（S00x）**：本轮不起草，P1 落地后再议。
