# Spec: S005 — 中长线价值选股漏斗（与短线 S002 并列）

> 状态：已通过（2026-07-29 签字）｜已实现（2026-07-29，见 验收报告.md）｜作者：Claude ｜日期：2026-07-29
> 关联：`../S002-打板工作流重构/spec.md`（短线，并列独立）、ai-berkshire `skills/industry-funnel.md` + `skills/quality-screen.md`、`CLAUDE.md` §0/§1
> 来源：移植 ai-berkshire 行业漏斗四层 + 去劣 7 条，适配 Vibe-Research 本地看板
> **定位：中长线价值选股漏斗，与短线打板漏斗 S002 并列，互不挂载、口径独立。**

---

## 0. 摘要

为 Vibe-Research 增设一条**中长线价值选股**路径：输入一个行业/方向/指数/主题，按四层漏斗从全市场逐层精选到 3 家终选——L1 全市场扫描（30-60 家）→ L2 去劣 7 条硬过滤 + 护城河软标注（≤10）→ L3 精细结构化分析（≤10）→ L4 四大师深度（3 家，文字交用户 AI）。每层留/弃标准明确、可复盘可追溯。

**本期范围：先只 A 股**；港股/美股去劣数据源预留（按 financial-data.md 的 aastocks/macrotrends），后续扩展。

与短线 S002 并列：不同时间框架（年 vs 日）、不同数据（财务三表 5-10 年 vs 量价/资金流）、不同输出（价值质量 vs 活跃度档），两条漏斗独立，不互相挂载。

**不做**：不做短线量价/资金流/打板（那是 S002）；不输出"一流/非一流"主观评价；不预测涨跌；不参考价位（研究模式另立）。

---

## 1. 背景与目标

- ai-berkshire 的 `industry-funnel`（四层精选到 3 家）+ `quality-screen`（去劣 7 条 + 3 豁免）是成熟的中长线价值选股方法，"宁可漏网不可误杀"。
- Vibe-Research 现有短线 S002 漏斗针对打板，无法承载中长线选股；用户两条线都要。
- **目标**：把这套中长线价值漏斗移植进 Vibe-Research，作为与 S002 并列的独立路径；四层每层可检视、留弃可复盘，去劣 7 条作 L2 粗筛，指标客观可复现。

---

## 2. 合规边界

- **客观过滤不主观评分**：去劣 7 条每条输出"通过/未通过/不适用"+数值+依据，汇总"通过 N/7"；**不输出"一流/非一流/劣质"主观评价**，不做综合主观评分。
- **呈现正反两面**：L3/L4 每家结构化分析附反面论据（与 ai-berkshire 核心原则一致）。
- **不预测涨跌/不给买卖时机**：漏斗结果仅是筛选与事实呈现，不构成买卖建议；估值历史分位只标位置不划买卖线。
- **四大师深度分析交用户 AI**：L4 的方向结论由用户配置的 AI 给出（依赖 S001 修复后的 `/api/chat`），系统只备数据与框架。

---

## 3. 用户角色

- **主用户**：同时做短线 + 中长线的个人投资者（自托管 Vibe-Research）。

---

## 4. 用户故事

- **US1 输入方向**：作为用户，我想输入一个行业/方向（如"AI算力""创新药"）、市场/指数（"沪深300""纳斯达克100"）或主题（"全球高股息"），系统先搜索相关主要上市公司（10-60 家）作为 L1 输入。
- **US2 四层漏斗**：我想看到 L1 扫描 → L2 去劣粗筛 → L3 精细分析 → L4 四大师深度 的逐层收敛，每层可检视输入/输出数与被弃标的+原因。
- **US3 去劣粗筛**：L2 对每只标的计算去劣 7 条 + 3 豁免，输出"通过/未通过/不适用"+数值+依据，汇总通过率，未通过者弃出（豁免命中者保留）。
- **US4 精细分析**：L3 对留下的每家做 300-500 字结构化分析（商业模式/护城河/财务/估值位置/风险），附反面论据。
- **US5 四大师深度**：L4 终选 3 家，每家四大师视角（巴菲特护城河/芒格逆向/段永平对的生意+人/李录文明趋势）800-1200 字，交用户 AI 给方向结论。
- **US6 豁免可见**：豁免 A/B/C 命中时标"豁免第N条"+依据，不被误判未通过。
- **US7 数据不足透明**：新股/次新/历史不足的标的，去劣标"不适用（数据不足）"+原因，不臆造、不补全。
- **US8 可复现**：任一层留/弃、任一指标可展示取数时点、年份区间、计算口径，可用 `financial_rigor.py` 复算核对。
- **US9 与短线独立**：中长线漏斗与短线 S002 候选池互不影响，结果分目录存储、分页面呈现。

## 5. 漏斗结构（移植 industry-funnel 四层 + 去劣 7 条作 L2）

| 层 | 名称 | 输入 | 留/弃标准 | 产出 |
|---|---|---|---|---|
| L1 | 全市场扫描 | 行业/方向/指数/主题 | 活跃度+涨幅+市值前 30 的并集（客观榜单） | 30-60 家候选 |
| L2 | 去劣粗筛 | L1 输出 | 去劣 7 条硬过滤（全部及格或豁免命中者保留）+ 护城河客观代理标注（软，不剔除） | ≤10 家 |
| L3 | 精细分析 | L2 输出 | 每家结构化分析 + 反面论据 | ≤10 家 |
| L4 | 四大师深度 | L3 输出 | 巴芒段李四视角 800-1200 字/家（数据由系统备，文字交用户 AI） | 3 家终选 |

### 5.1 去劣 7 条（L2 粗筛，移植 quality-screen）

| # | 指标 | 排除条件 |
|---|---|---|
| 1 | 10年平均ROE | < 8% |
| 2 | 5年累计自由现金流 | 为负 |
| 3 | 利息覆盖倍数（EBIT/利息） | < 2倍（银行/保险不适用） |
| 4 | 长期毛利率 | < 15% |
| 5 | 经营现金流/净利润（5年均值） | < 0.7 |
| 6 | 长期净利率 | < 5% |
| 7 | 5年总股本膨胀 | > 20%（非并购原因） |

### 5.2 三条豁免（防误杀）
- **A 战略投入期**（适用于第1条）：营收连续高增长 + 战略投入致短期盈利承压 + 成长性赛道。
- **B 周期底部**（适用于第1/2/6条）：行业周期底部，历史盈利被压低，但现金流/资产负债表健康。
- **C 护城河补偿**：强护城河（品牌/网络/规模/转换成本），可对单条不达标适度容忍。

> 豁免须标依据，客观可述；最终认定交用户 AI/用户（系统只提示"可能命中豁免X"）。

### 5.3 护城河软层（L2 并行标注，不剔除）

去劣 7 条是**硬过滤**（未通过即弃出 L2）；护城河是**软标注**（不剔除，仅作为 L3/L4 的输入信号）。为守合规红线（不主观评分），护城河层**只呈现客观可识别的代理信号**，综合判断交用户 AI：

- 高毛利率持续性（多年 >30% 标"定价权信号"）
- 市占率/行业排名（客观榜单位置）
- ROE 长期均值与稳定性
- 品牌/网络/规模/转换成本的可识别客观证据（如用户数、市占率、专利数等公开数据）

> 系统不输出"护城河★★★"主观评分；只摆代理信号，护城河强度判断交用户 AI。

## 6. 与 S002（短线）的关系

| 维度 | S002 短线漏斗 | S005 中长线漏斗 |
|---|---|---|
| 时间框架 | 日/周 | 年 |
| 数据 | 涨停四池/资金流/龙虎榜/竞价 | 财务三表 5-10 年 |
| 粗筛口径 | 活跃度档（换手/量比/成交额） | 去劣 7 条（ROE/FCF/利息覆盖…） |
| 输出 | 活跃度档 + 企稳信号 | 通过 N/7 + 结构化分析 + 四大师深度 |
| 终选 | 候选池（不固定家数） | 3 家 |
| 页面/存储 | /candidates | /value-funnel（独立目录） |

两漏斗独立，不互挂载、不共享粗筛口径；财务数据均经 `astock.em_get` 限流取数。

## 7. 验收标准

- **AC1**：输入行业/方向/指数/主题，L1 搜索主要上市公司 10-60 家并输出。
- **AC2**：四层逐层收敛，每层可检视输入/输出数与被弃标的+原因。
- **AC3**：L2 对每只标的计算去劣 7 条，输出"通过/未通过/不适用"+数值+依据；通过率**双口径**展示（绝对 N/7 + 调整 N/(7−不适用)）；未通过者弃出，豁免命中者保留；护城河代理信号并行标注（不剔除）。
- **AC4**：L3 每家结构化分析含反面论据。
- **AC5**：L4 终选 3 家，四大师视角各 800-1200 字；**系统备数据与框架骨架，文字分析交用户 AI 产出**（依赖 S001 修复后的 `/api/chat`；未修前 L4 仅出数据骨架与要点清单）。
- **AC6**：豁免 A/B/C 命中标依据，该条不计未通过。
- **AC7**：新股/次新/历史不足标"不适用（数据不足）"，不剔除、不补全；通过率分母调整（通过 N/(7−不适用)）。
- **AC8**：任一留/弃、任一指标可展示取数时点/年份区间/口径，可用 `financial_rigor.py` 复算。
- **AC9**：与 S002 短线池独立，互不影响，结果分目录分页面。
- **AC10**：不输出"一流/非一流/劣质"主观结论词，只出各条客观事实 + 结构化分析。

## 8. 边界情况

| 场景 | 处理 |
|---|---|
| 新股/次新（<10年历史） | 数据年限 ≥5 年可算（降级口径，标"数据年限不足10年"）；<5 年标"不适用（数据不足）"，L2 不剔除但标"需人工判断" |
| 周期股（ROE/利润大波动） | 第1/2/6条结合豁免B周期底部判定，标依据 |
| 银行/保险 | 第3条利息覆盖标"不适用" |
| 并购导致股本膨胀 | 第7条标"并购所致，不计未通过"，需依据 |
| 财务数据源缺失 | 对应条标"未取得"+原因，分母调整，不补全 |
| 港股/美股标的 | 去劣口径不变，数据源按 financial-data.md（aastocks/macrotrends） |
| 未上市候选 | L1 可含未上市候选（标注"未上市"），L2 去劣不适用（无公开财务），直接进 L3 人工分析 |
| ST/*ST/退市 | L1 即剔除，不入漏斗 |
| L1 候选不足 | 提示"该方向可研究对象不足 N 家"，放宽搜索或终止 |
| L2 全部未通过 | 提示"无符合价值标准的标的"，不强行产出 3 家 |

## 9. 非目标

- 不做短线量价/资金流/打板（S002 范围）。
- 不接入 S002 短线漏斗，不共享粗筛口径。
- 不输出"一流/非一流"主观评价或综合质量评分。
- 不预测涨跌、不给买卖时机、不参考价位（研究模式 S00x）。
- 不改数据层实现，复用 astock 财务端点（经 em_get 限流）。
- 不替代用户 AI 的方向判断（L4 结论交 AI）。

---

## 10. 决议（已签字 2026-07-29）

1. ✅ **L2 粗筛口径**：去劣 7 条作**硬过滤** + 护城河**软标注**（不剔除，只摆客观代理信号，综合判断交用户 AI）。
2. ✅ **通过率分母**：**双口径**——绝对 N/7 + 调整 N/(7−不适用条数)，同时展示。
3. ✅ **L4 四大师产出**：系统备数据与框架骨架，四大师文字分析**交用户 AI** 产出（依赖 S001 修复后的 `/api/chat`；未修前 L4 仅出数据骨架+要点清单）。
4. ✅ **数据年限**：**最低 5 年可算**（降级口径，标"数据年限不足10年"）；<5 年标"不适用（数据不足）"。
5. ✅ **跨市场**：**本期先只 A 股**；港股/美股去劣数据源预留（按 financial-data.md 的 aastocks/macrotrends），后续扩展。
