- [D][B] 005: 筹码结构数据提取——每只取 turnover_pct（换手率）、vol_ratio（量比）、amount（成交额），从 `tencent_quote` 实时或 `market._emotion` 缓存取
- [D][B] 006: 板块归属数据提取——每只取 industry（行业）+ concept（题材），从 `astock.concept_blocks` 或 `code_industry` 表取

### 1b：三层剔除逻辑

- [B] 007: 剔除层1 封板质量——break_times≥2 剔除 / first_seal≥14:00 剔除 / seal_amount<float_cap*0.5% 剔除，返回 (kept, filtered_records)
- [B] 008: 剔除层2 筹码结构——turnover>25% 剔除 / amount>15亿 剔除 / vol_ratio≥2.0 剔除，返回 (kept, filtered_records)
- [B] 009: 剔除层3 市场环境（T-1粗筛）——大盘跌>1.5% 标记"高风险"（不剔除） / 同板块涨停<2只且无题材 剔除 / 连板梯队最高板断裂 剔除，返回 (kept, filtered_records)
- [B] 010: 剔除结果聚合——三层串联，输出候选池 list[code] + 剔除原因 dict[code→[layer, reason]]

### 1c：8维度评分

- [B] 011: 评分维度1 板块评分(20%)——调 `sector_cycle.aggregate_sectors` / `sector_strength_rank`，板块涨停≥3只加分，0-100归一化
- [B] 012: 评分维度2 游资画像(15%)——调 `hot_money_seats.compute_seat_risk_factor`，一日游占比高→×0.7扣分，接力型→加分，0-100归一化
- [B] 013: 评分维度3 封板强度(20%)——封单/流通市值比(>1%=满分) + 首封时间(<10:00=满分) + 炸板次数(0=满分)，加权0-100
- [B] 014: 评分维度4 筹码结构(10%)——换手5-20%=满分 / 量比<1=满分 / 成交额<5亿=满分，加权0-100
- [B] 015: 评分维度5 竞价确认(10%)——T日9:25 竞价高开1-3%=满分 / 竞价量≥昨日5%成交量=满分（T日盘前实时，T-1盘后预填0待T日更新）
- [B] 016: 评分维度6 北向资金(10%)——调 `astock.hsgt_realtime` 取个股北向净流入，正流入加分（北向新规收紧降级0）
- [B] 017: 评分维度7 龙虎榜机构(10%)——调龙虎榜数据取机构净买入，正净买入加分（无龙虎榜数据降级50分）
- [B] 018: 评分维度8 题材热度(5%)——调 `astock.ths_limit_up_pool` 取 reason 聚合，同题材涨停≥3只=满热度
- [B] 019: 评分维度9 事件评分(5%)——调 catalyst `classify_announcement`，#33/#34利多(预增/重组/回购)加分 + #35-39利空(减持/解禁/业绩雷)扣分，无公告=50分中性
- [B] 020: 9维度加权总分——sum(维度i * 权重i)，权重：板块15%+游资15%+封板20%+筹码10%+竞价10%+北向10%+机构10%+题材5%+事件5%，按总分降序排序候选池
- [B] 021: 评分落盘——每只候选记录9维度分+总分+排序序号，存 `~/.vibe-research/first_board_scores_{date}.json`
