### 关键原则（60日复验窗口，grill 2026-08-17）

> §44 从"硬约束 bar"改为"60日复验窗口"：选股逻辑是多轮 grill 决议的量化经验（非拍脑袋），当前可接入跑通；§44 统计结论作为诚实标注（标"未 validated"），不阻断接入；60日数据积累后复验，破2x→validated 升级权重，<2x→标注保留或降权。
> 与 spec line 32"等60天~2026-09-20复验"一致。

1. **§44 统计结论是诚实标注，非接入阻断**：within-day r≈0 / lift<2x 的因子标"未 validated"，但仍可接入跑通（等权 placeholder 或量化经验权重）。统计结论诚实告知用户"该因子未达统计显著"，不因此移除。
2. **60日复验窗口**：当前 eastmoney_live 24天<30 标"探索性"。等60天积累（~2026-09-20）复验——破2x+CI不重叠→validated 升级权重；<2x→保留接入但标注"复验未破2x"；方向反转→移除或反转。
3. **本地计算不改变统计结论，但可接入跑通**：MA/BOLL/筹码等因子可本地计算并接入（量化经验判断有价值），但必须标注"§44未验证"，60日复验时一并验证。算出来不等于有效，跑通不等于 validated。
4. **数据缺失标注 ≠ 因子有效**：因子"常 None"标注 missing 是诚实降级，不通过补数据暗示有效。

## 容错降级与打分解耦（grill 2026-08-17）

> 采纳"容错降级与软硬解耦"原则，与 §4.4 反向因子删除、§5.4 板块热度降级 label、Q7 天气降软标注的决议一致。不采纳"补齐已废弃数据源"部分。

### 软硬解耦原则

| 因子类型 | 过滤行为 | 理由 |
|---|---|---|
| **§44 未 validated**（涨停五因子/MA/BOLL/筹码） | 接入跑通，标注"§44未验证/探索性"，**不硬过滤** | 选股逻辑多轮grill决议，可跑通；统计结论诚实标注非阻断；60日复验后定权重 |
| **§44 弱正非 validated**（breakout_20d） | 接入但标注"弱信号 honest"（S071 已做），**不硬过滤** | robust>1 但 <2x，可参考非决策依据；60日复验后若破2x升级 |
| **§44 方向证伪**（板块热度/反向因子） | 纯 label 不接策略分或删除，**不硬过滤** | 方向被驳的因子不接策略分（§5.4/§4.4 决议）；60日复验方向不变则保持 |
| **常态缺失因子**（大宗交易/股东户数） | missing→中性不扣分（0 分），**不硬过滤** | 数据缺失≠因子不达标，硬过滤会误杀标的 |
| **Q7 天气推荐** | 软标注（推荐徽标），**不硬过滤** | T-1 天气不代表 T 日，强约束致 0 候选比无约束更有害 |
| **暴风雨** | 唯一保留硬约束（仓位=0） | 极端环境需强制熔断 |

### 数据缺失时的降级路径

```
因子数据缺失 → 中性化（值=0 或中性 label）→ 不参与打分/不过滤 → 标注 missing
                                                              ↓
                                                  非硬过滤路径，候选不被误杀
```

### 与 R3 降级逻辑的呼应

`backend/candidate_funnel/funnel.py:386-397` 已落地 R3 数据缺失降级：auction={}+catalyst={} → R3=R2 输出（非全过滤）。这是"容错降级"原则在漏斗层的实现——数据缺失时保留上游输出而非误杀全部。
