## 7. 修订记录

- **2026-07-29 HIGH-1**：`sources/activity.py` 成交额读取键 `amount`/`amount_yi` 与 `astock._parse_gtimg` 实际返回键 `amount_wan`（万）不符，导致 `amount_yi` 恒 None → ①AC6 把代码 bug 误标为"未取得"；②`assess_activity` 第 47 行"成交额≥10亿"规则永不命中，"有资金容量"维度静默死亡。修复：改读 `amount_wan` 并 `/10000` 换算成亿（0.0 不被 `or` 吞）。新增 `test_sources_contract.py` 用真实 `_parse_gtimg` 形状 fixture 堵住该盲区。该 bug 被 `test_financial_rigor.py` 漏过（后者直接喂 `amount_yi`，不经 activity.py 映射）。live 实测：茅台 amount_yi=29.2 亿 ✓。
- **2026-07-29 HIGH-3**（live 复核暴露）：`sources/fund_flow.py` `main_net_inflow`/`main_net_5d` 直接透传 `astock.stock_fund_flow_120d` 的 `main_net`（单位**元**），但模型/诊断卡口径为"万" → 诊断卡显示 511920064 万（实应 51192 万=5.1 亿）。修复：`/10000` 换算到万（`dragon_tiger_inst_net` 已为万，不二次换算）。契约测试改用真实元值 fixture。live 实测：茅台 main_net_inflow=51192 万 ✓。
- **2026-07-29 HIGH-4**（live 复核暴露）：`sources/gene.py` 调 `limitup_screener.get_screener_result`（`async def`）未 await → 返回 coroutine，`gene_scores` 取不到 → `fetch_genes` live 静默返 `{}`，**R1 涨停基因得分整层空**。离线测试因 mock 绕过未发现（live 测试断言太弱也漏过）。修复：新增 `_await()` 在 sync 上下文跑 async 函数（无 running loop 用 `asyncio.run`，有则独立线程起新 loop）。live 实测：gene 返 27 条 ✓，coroutine 告警消失。
- **2026-07-29 HIGH-5**（用 Claude 订阅 CLI 实测「问 AI」暴露）：`cli_runtime.run_cli`/`run_cli_stream` 用 `text=True` 但不指定 `encoding`，Windows cp936 本机 locale 下以 GBK 解码 `claude.CMD` 的 UTF-8 stdout → `UnicodeDecodeError` 被 `_pump` 的 bare `except: pass` 吞掉 → 订阅 CLI 接入（含诊断卡 AskAiButton）**静默返空内容**（流式只有 `done` 无 `delta`）。修复：Popen/run 加 `encoding="utf-8", errors="replace"`。新增 `tests/test_cli_runtime.py` 锁住该不变量（不导入 app，可独立 collect）。实测：`chat.run_chat_cli_stream`（即 `routers/chat.py:71` 调的生成器）用 cli-claude 配置产出 `['delta','done']` 事件、69 字合规答案 ✓。
