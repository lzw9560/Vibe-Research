## 偏差与待办（需决策）

### 1. 东财 push2/push2his——缺 ut token（根因，非端点宕）+ IP 限流
- **根因发现**：push2/push2his 端点本身可用，但需 `ut` token；astock 旧函数（`stock_fund_flow_120d`/`concept_blocks`）缺 ut → 返空/断连（此前误判为"端点宕"）。
- 验证：push2 clist + ut → 200+真实板块资金流（电子 f62=267亿…）；push2his fflow + ut → 200+klines；push2 slist + ut → data:null（concept_blocks 需另行修复，非仅 ut）。
- **IP 限流**：本会话探测过多触发东财 IP 限流（冷却 60s 仍 RemoteDisconnected），live 验证短期受阻，需数小时冷却。
- **bonus 修复（未做，data 层 scope 外）**：`stock_fund_flow_120d` 加 ut 即修 main_net（app-wide，28 消费者）；`concept_blocks` 需更多（slist data:null）。

### 2. R1 北向——2024-08-19 规则变更后个股日级北向停更
- `RPT_MUTUAL_HOLDSTOCKNDATE_STA` 数据仅到 2024-08-16（规则变更日）。
- 近期日期（post-change，漏斗 T-1 实际用途）→ `fetch_northbound` 返 None=missing（spec §9 回退，不臆造）。
- 历史 backfill（pre-change）有数据（live 验证 20916.5万）。
- **影响**：R1 对漏斗当前用途实际值≈missing；仅历史回填有用。`NorthFlowSegmenter.RULE_CHANGE_DATE` 已预见。

### 3. R2 板块资金流——已接线 + live 修复（2026-08-10 收尾）
- **live 验证通过**：600519（贵州茅台，行业「白酒Ⅱ」）=92372.0 万元、000001（平安银行，「银行Ⅱ」）=18511.3 万元；板块缓存 456 条（496 原始去归一化碰撞）。
- **修复 3 个 mock 测不出的 live 真 bug**：
  1. **行业源换掉**：原走 `astock.individual_info`（akshare `stock_individual_info_em`）——其 push2 `stock/get` **缺 ut** 被断连（且不走 em_get），行业腿 live 从未通过。改 `push2delay.eastmoney.com/api/qt/stock/get` + ut 取 f127（行业为静态属性，delay host 足够；push2 主host stock/get 限流未恢复）。
  2. **板块分页取全**：行业板块共 ~496 个（`fs=m:90+t:2`），服务端单页上限 100——原实现只取第一页（白酒不在第一页）→ 匹配不上。现翻页取全（pz=100，≤8 页）。
  3. **级别后缀归一化**：f127 行业带级别后缀（「白酒Ⅱ」），板块名有的带有的不带（「白酒Ⅱ」/「银行」）——归一化去 Ⅰ/Ⅱ/Ⅲ 后匹配。
- **防封加固**：板块 clist TTL 缓存 10min（漏斗逐候选复用，不逐候选重发）；push2→push2delay 降级（与 market_turnover_rank 同款）。
- **防未来函数**：`date < 今日` → None（端点仅当日值，不得拿今日资金流冒充历史数据）；与 activity 历史分支语义一致。
- push2 slist（concept_blocks）带 ut 仍 data:null——concept_blocks 另行处理（20db0d5 调查：无需额外修）；不影响 R2（R2 用 clist 行业板块，不用 slist）。
