*ST 两层分离
验证层（保留 *ST）
*ST/即将退市股不剔，保"不剔除退市"一致性。*ST 是退市前奏，剔 *ST = 删 value trap 尾部 = 美化 value = 假 edge。

实盘不买 *ST。涨跌停 +/-5% + 流动性差 + 退市风险。验证含 *ST 尾部保守，capture 须 *ST filter。

deferred 因子 + 数据 caveat

spec 承认的局限与待验项

F2PE+ROE composite（Family C K=1）deferred：earnings_yield_rank + roeAvg_rank。须数据够才跑。roeAvg 是 YTD 累计非 TTM，须取自 F1 同一 pubDate<D quarter 行防字段漂移。
F3Low PB（高 B/M）deferred：BVPS=epsTTM/roeAvg 对 3/4 季度失效（roeAvg YTD vs epsTTM TTM 口径不匹配），仅 Q4 年报可用。先 Q4-only 验证。
PEPE 是 pragmatic proxy 非 canonical B/M：Fama-French HML 用 book-to-market，baostock 无 BVPS 字段。PE 因 epsTTM 直接可得，是数据可得性驱动非 A 股证据驱动。
!restatement risk：baostock 可能存 restated（修正后）epsTTM 但保留原始 pubDate。pubDate<D 保证报告已公开，不保证值是 as-originally-reported。抽样验证 5-10 stock-quarters，偏差大降级。
!turnover sensitivity 待实测：round_trip_cost=0.0025，harness 预扣。turnover 须首跑后实测月度 quintile 变化率，不可假设 50%。月度换手 20-50%+，年 drag 可能 3% 非 1.5%（A 股 value premium 3-5%/yr gross，3% drag 可能翻 verdict）。deferred 到首跑后加 sensitivity。
!月度 autocorrelation：月度 value portfolio 组合慢变（同股连续月在 bottom-quintile），跨月自相关违反 iid 假设。day_clustered t-test 的 se 假设月均值独立，自相关时 t 略偏高。selection permutation（月内 cross-sectional）不受影响。Newey-West HAC SE deferred（caveat 标注，PurgedKFold 补 OOS）。
