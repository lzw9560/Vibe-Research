# Spec: S075 — 首板流（首板涨停股 T+1 操作工作流）

> **状态**：spec 草案，待 grill
> **级别**：medium（新工作流环节 + 复用现有数据源）
> **起因**：§44 证伪涨停五因子横截面选股力，但涨停股 vs 非涨停股次日溢价差异真实存在。从"找涨停股中谁最好"转向"剔除首板涨停股中谁会亏"。首板流是首个工作流，其他战法（连板/炸板回封等）适配后续工作流。

## 1. SOURCE_OF_TRUTH

### 1.1 定义

**首板流** = 首板涨停股（当日首次涨停，非连板）的 T+1 操作工作流。

T-1 日首板涨停 → T 日建仓 → T+1 日卖出，完整闭环。

**范围**：只做首板（`lbc=1` 或首板），剔除≥2板连板。连板/炸板回封等适配其他工作流。

### 1.2 策略前提（已确认）

| 约束 | 值 |
|---|---|
| 交易制度 | A 股 T+1，当日买入不能卖出 |
| 信号日 | T-1 日首板涨停（首次涨停，非连板） |
| 建仓日 | T 日 9:35-9:45（10分钟开盘确认窗口） |
| 卖出日 | T+1 日（竞价/开盘卖为默认，盘中冲高>5%提前止盈） |
| 持仓周期 | 1 日 |
| 仓位 | 选 3-5 只，等权 |
| 选股思路 | 否定式（剔除不良），不排序不打分 |

### 1.3 代码基线（已有可复用）

| 组件 | 文件 | 复用点 |
|---|---|---|
| 涨停四池 | `market._emotion` / `astock.em_zt_topic_pool` | 涨停池含 `lbc`（连板数），`lbc=1` 过滤首板 |
| 竞价预计算 | `auction_screener.py` | 盘后批量分析 + 次日竞价预案 |
| 溢价规律 | `docs/a-share-patterns.md` | 首板溢价>连板溢价（2.3定律）+ 封板时间/换手/缩量等 |
| 仓位/止损 | `position_advisor.py` | PositionParams(stop_loss/take_profit/max_hold_days) |
| 工作流框架 | `trading_workflow.py` | get_current_stage() 阶段判定 |
| 前向测试 | `forward_test.py` | §44 复验窗口四态 |
| 盘后调度 | `scheduled_tasks.py` | sti_post_market/candidate_funnel_precompute |

### 1.4 核心设计原则

1. **只用剔除不用排序**——§44 证伪横截面排序，binary 剔除不需要 r>0
2. **剔除条件有交易逻辑支撑**——每个阈值有 a-share-patterns.md 定律支撑
3. **T+1 约束驱动时点**——建仓10分钟确认避开竞价核按钮，T+1 卖出不贪婪
4. **工作流形式嵌入**——是 WR-Workflow 时序内的子闭环，不是独立战法
5. **只做首板**——首板是新事件驱动，溢价确定性高于连板（a-share-patterns.md 2.3）

### 2.2 ① 筛选（T-1 盘后，post_market 环节）

**前置过滤**：只取首板（`lbc=1`），剔除所有连板（`lbc≥2`）

三层剔除：

```
T-1 日盘后：当日首板涨停池（lbc=1，~30-60只）
    │
    ▼
【剔除层 1：封板质量】
    ├ 剔除：炸板次数≥2（首板就炸=封板意愿极弱）
    │   依据：ZTPoolItem.break_times，首板炸2次=资金严重分歧
    ├ 剔除：首次封板时间≥14:00（尾盘偷袭，次日溢价低）
    │   依据：a-share-patterns.md 2.4 14:30后封板溢价低
    ├ 剔除：封单金额<流通市值0.5%（封板资金不足）
    │   依据：a-share-patterns.md 封单/流通市值比>1%=强（反向剔除）
    └ 保留：~20-40只
    │
    ▼
【剔除层 2：筹码结构】
    ├ 剔除：换手率>25%（筹码松动，主力出货）
    │   依据：a-share-patterns.md 3.3 换手5-20%健康，>20%松动
    ├ 剔除：成交额>15亿（过大盘，次日资金接不动）
    │   依据：a-share-patterns.md 1.6 成交额小更易封板（反向剔除过大）
    ├ 剔除：量比≥2.0（放量过度，次日回调风险）
    │   依据：a-share-patterns.md 2.5 缩量涨停次日胜率高（反向剔除放量）
    └ 保留：~10-25只
    │
    ▼
【剔除层 3：市场环境】
    ├ 剔除：大盘跌幅>1.5%且个股逆势涨停（孤岛，次日补跌风险）
    │   依据：a-share-patterns.md 大盘宽度
    ├ 剔除：同板块涨停<2只且无题材归因（孤立首板，无联动）
    │   依据：a-share-patterns.md 4.1 同板块≥2只=联动强
    ├ 剔除：连板梯队最高板断裂（情绪退潮，首板也受影响）
    │   依据：a-share-patterns.md 4.3 龙头断板=退潮
    └ 保留：~5-15只 = 候选池
```

### 2.3 ② 确认（T 日 9:25-9:40，pre_market → intraday 环节）

```
T 日 9:25 竞价观察（不建仓）
    ├ 竞价高开>5% → 放弃（溢价已吃，追高风险）
    ├ 竞价低开 → 放弃（核按钮风险）
    └ 竞价温和高开 1-3% → 进入观察
    │
    ▼
T 日 9:30-9:40 开盘10分钟确认
    ├ 确认强势（同时满足）：
    │   ├ 开盘高开 1-3%
    │   ├ 5分钟内不破开盘价（买盘支撑）
    │   └ 量比>1.5（资金参与度）
    ├ 确认强势 → 进入建仓
    └ 未确认 → 放弃该标的
```

### 2.4 ③ 建仓（T 日 9:35-9:45，intraday 环节）

```
等权买入前 3-5 只（按确认时间排序，先确认先买）
    ├ 单股仓位 20-33%（3-5只等权）
    ├ 暴风雨天气 → 仓位=0（现有硬约束）
    └ 达5只后停止建仓
```

### 2.5 ④ 卖出（T+1 日 9:25-9:30）

```
T+1 日（首板流不做连板持有，T+1 必卖）
    ├ 默认：9:25 竞价/9:30 开盘卖出（快进快出，锁溢价）
    ├ 盘中冲高>5% → 提前止盈
    └ 盘中跌破-3% → 止损（不等回本）
```

**注**：首板流 T+1 必卖——首板次日不连板的概率高（首板→二板晋级率约20-30%），不赌连板。

### 2.6 ⑤ 结算（T+1 盘后，post_market 环节）

```
T+1 盘后
    ├ 盈亏归因：每只记录 entry_price/exit_price/return_pct
    ├ 入 PostMarketReview 三问（推了什么/买了什么/漏了什么）
    ├ 入 forward_test 信号账（§44 复验窗口算 lift）
    └ 漏的票（候选池未建仓的）记录次日收益（漏单对账）
```

### 2.7 仓位与风控

| 参数 | 值 | 依据 |
|---|---|---|
| 单股仓位 | 20-33%（3-5只等权） | 分散但不过度 |
| 止损 | -3% | T+1 不能再等 |
| 止盈 | +5% 盘中冲高 | 不贪婪，锁利 |
| 最大持仓 | 5只 | 仓位集中度上限 |
| 暴风雨 | 仓位=0 | 现有硬约束 |
| T+1 必卖 | 不赌连板 | 首板→二板晋级率低 |
