## 4. 备选方案 + 为何不选

- **window-sanity 用 harness-side 按胜出窗口调 edge_type（两者都做）** → 不选：data-snooping（选择偏差）——按结果最好看的 edge_type inflate Type I error，Bonferroni 不覆盖。对抗审 wjiq1hkmz CRITICAL 修正，用户同意 supersede。verifier-side R5 查 ALL + 双算 metrics 让 selection 策略隔夜 edge 也被测（当前 :343 只在 event_edge_types 算），无选择偏差
- **R3 enforce 重写 trade_journal.py 接 lift_to_multiplier** → 不选：trade_journal.py:399-400 实测是 query_winrate_trends 显示标签（原文'标签 robust 仅统计意义，不触发 sizing 调整'），非 sizing 路径。重写它=改错文件。真实 gap 在 seed.py R3 task reminder→enforce + evaluation.py DIM_ARM_MAP arm-sizing 空转
- **Bonferroni K>8 用 BH（Benjamini-Hochberg）替代** → 不选：决策#9 不用 BH。verifier.py:299-303 硬编码 selection 只 Bonferroni。引入 BH 须改 verifier 给 selection 也算 p_bh=方法论变更须 grill。拆≤8 子 phase 保 Bonferroni 严格 + alpha_adj 正确（:33 _MAX_BONFERRONI_K=8 cap 原意就是拆）
- **family grouping 直接 p×n（raw 30 策略）不去重等价** → 不选：bollinger==zscore 数学等价、triple_ma≈ema_ribbon、macd≈rsi_momentum——不去重则 n=30 过度校正（alpha_adj=0.05/30 太严），effective families ~9-15。去重最简单（:324 bonferroni_bh 当前无 family 逻辑）
- **baostock pctChg 注入改 bar_utils.py:62 源码** → 不选：决策#12 harness 层注入。保 bar_utils.py 源码干净（共享 bar 工具被 engine+strategies 共用），注入在回测数据准备阶段
- **escalation 自动晋级到 monitoring/holding（自动买入）** → 不选：决策#11 只 candidate→watching 自动。A 股 T+1 容错率低，auto-fire holding=自动买入不可当日卖；社区阈值未验证（标探索性）。watching 以上人工（半自动化助手定位）
