## 2. 图谱内容（四构件：实体/关系/逻辑规则/动作）

### 实体

| 实体类 | 实例 | 属性 |
|---|---|---|
| 缺口类型 | 普通缺口 / 突破缺口 / 持续缺口 / 衰竭缺口 | 出现位置、回补速度、量比、实战意义 |
| 缺口方向 | 向上缺口 / 向下缺口 | 多头抢筹 / 空头砸盘 |
| regime 状态 | 趋势启动 / 趋势中继 / 反转 / 噪声 | 对应缺口类型 + 多空动能 |
| 判定规则 | 量比≥2.0 / 3日不回补 / 20日前高压力位 | 量化阈值（S193 实现） |
| 信号关系 | 缺口 regime ↔ OFI / 选股 / 资金流 / 趋势臂 | 融合层互补/冗余（S194 验） |

### 关系

- 突破缺口 → 趋势启动 regime（多空动能转多头）
- 衰竭缺口 → 反转 regime（动能衰竭）
- 持续缺口 → 趋势中继 regime（动能延续）
- 普通缺口 → 噪声 regime（无动能转换）
- 缺口 regime → [[breakout 选股]]（候选池注入，辅助择时）
- 缺口 regime → [[趋势臂 S181]]（突破后趋势 regime 切趋势臂，但不自动切）
- 缺口 regime → [[T+0 OFI S189]]（不同信号源——缺口日级价格事件 vs OFI 盘中盘口，融合互补非冗余）
- 缺口 regime → [[信号融合基线 S194]]（作融合池一信号，F1 消融验增量）

### 逻辑规则

- **回补速度**是缺口核心判断标准（长不回补=主导方强）
- **突破缺口**：量比≥2.0 + 3 日不回补 + 在 20 日前高压力位 → 趋势启动
- **衰竭缺口**：第三个缺口 + 异常放量(量比≥3)或缩量(量比<1) → 反转
- **A 股做空受限**：向下缺口仅 regime 判断 + 减仓预警，不裸做空（§1.1 弱合规）

### 动作

- 缺口 regime 判定后：**喂 AI 综合研判**（不直接触发买卖，Q10-Q11）
- 关注标的 出现突破/衰竭缺口 → 飞书推送提醒（S193 R4）
- 候选池标的 → 缺口 regime 注入 AI 研判 context（S193 R3）
