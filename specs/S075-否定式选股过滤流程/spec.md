# Spec: S075 — 否定式选股过滤流程（剔除不良标的）

> **状态**：spec 草案，待 grill
> **级别**：medium（新过滤层 + 复用现有数据源，不碰外部新数据源）
> **起因**：§44 证伪涨停五因子横截面选股力（within-day r≈0），但涨停股 vs 非涨停股的次日溢价差异真实存在。从"找涨停股中谁最好"（已证伪）转向"剔除涨停股中谁会亏"（否定式选股）。

## 1. SOURCE_OF_TRUTH

### 1.1 策略前提（已确认）

- **交易制度**：A 股 T+1，当日买入不能卖出
- **信号日**：T-1 日涨停
- **建仓日**：T 日，9:35-9:45（10分钟开盘确认窗口）
- **卖出日**：T+1 日（竞价/开盘卖为默认，盘中冲高>5%提前止盈）
- **持仓周期**：1 日（T 日建仓 → T+1 日卖出）
- **仓位**：选 3-5 只，等权
- **选股思路**：否定式（剔除不良），不排序不打分（§44 证伪排序基础）

### 1.2 代码基线（已有可复用）

| 组件 | 文件 | 复用点 |
|---|---|---|
| 涨停四池 | `market._emotion` / `astock.em_zt_topic_pool` | 涨停池+炸板池+跌停池+昨涨停池 |
| 竞价预计算 | `auction_screener.py` | 已有盘后批量分析 + 次日竞价预案 |
| 溢价规律 | `docs/a-share-patterns.md` | 封板时间/换手/连板/缩量等定律 |
| 仓位/止损 | `position_advisor.py` | PositionParams(stop_loss/take_profit/max_hold_days) |
| 基因分 | `limitup_screener` | GeneScore.factors（§44证伪排序力，但因子值可作 binary 剔除阈值） |
| 前向测试 | `forward_test.py` | §44 复验窗口四态，验证新流程 lift |

### 1.3 核心设计原则

1. **只用剔除不用排序**——§44 证伪了横截面排序，但 binary 剔除不需要 r>0
2. **剔除条件有交易逻辑支撑**（非数据拟合）——每个阈值有 a-share-patterns.md 定律或交易共识支撑
3. **T+1 约束驱动时点设计**——建仓需10分钟确认（避开竞价核按钮），T+1 卖出不贪婪
4. **不依赖 §44 已证伪因子做排序**——封板率/红盘率等只作 binary 阈值（如换手>25%剔除），不连续打分

## 2. ARCHITECTURE_ROADMAP

### 2.1 三层剔除流程

```
T-1 日盘后：当日涨停池（~60-110只）
    │
    ▼
【剔除层 1：封板质量】
    ├ 剔除：炸板次数≥3（封板意愿极弱，反复开板=资金分歧）
    │   依据：a-share-patterns.md 2.2 炸板回封 + ZTPoolItem.break_times
    ├ 剔除：首次封板时间≥14:00（尾盘偷袭，次日溢价低）
    │   依据：a-share-patterns.md 2.4 14:30后封板溢价低 + ZTPoolItem.first_seal_time
    ├ 剔除：封单金额<流通市值0.5%（封板资金不足，封板意愿弱）
    │   依据：a-share-patterns.md 封单/流通市值比>1%=封板意愿极强（反向剔除）
    └ 保留：~40-70只
    │
    ▼
【剔除层 2：筹码结构】
    ├ 剔除：连续涨停≥6板（过度透支，断板风险极高）
    │   依据：a-share-patterns.md 4.2 连板高度递减效应 + ZTPoolItem.lbc
    ├ 剔除：换手率>25%（筹码松动，主力出货）
    │   依据：a-share-patterns.md 3.3 换手5-20%健康，>20%松动 + tencent_quote.turnover_pct
    ├ 剔除：成交额>15亿（过大盘，次日资金接不动）
    │   依据：a-share-patterns.md 1.6 成交额小<5亿更易封板（反向剔除过大）
    └ 保留：~20-40只
    │
    ▼
【剔除层 3：市场环境】
    ├ 剔除：大盘跌幅>1.5%且个股逆势涨停（孤岛，次日补跌风险）
    │   依据：a-share-patterns.md 大盘宽度 + 逆势涨停虽强但孤立时风险高
    ├ 剔除：同板块涨停<2只且无题材归因（孤立涨停，无联动）
    │   依据：a-share-patterns.md 4.1 同板块涨停≥2只=联动强（反向剔除孤立）
    ├ 剔除：连板梯队最高板断裂（情绪退潮信号）
    │   依据：a-share-patterns.md 4.3 龙头断板=退潮 + STI ladder
    └ 保留：~10-25只 = 候选池
```

### 2.2 T 日建仓确认流程

```
T 日 9:25 竞价观察（不建仓）
    ├ 竞价高开>5% → 放弃（溢价已吃，追高风险）
    ├ 竞价低开 → 放弃（核按钮风险）
    └ 竞价温和高开 1-3% → 进入观察
    │
    ▼
T 日 9:30-9:40 开盘10分钟确认
    ├ 确认强势（同时满足）：
    │   ├ 开盘高开 1-3%
    │   ├ 5分钟内不破开盘价（买盘支撑）
    │   └ 量比>1.5（资金参与度）
    ├ 确认强势 → 9:35-9:45 建仓
    └ 未确认 → 放弃该标的
    │
    ▼
等权买入前 3-5 只（按确认时间排序，先确认先买）
```

### 2.3 T+1 日卖出流程

```
T+1 日
    ├ 9:25 竞价/9:30 开盘卖出（默认，快进快出）
    ├ 盘中冲高>5% → 提前止盈（不贪婪等更高）
    ├ 盘中跌破-3% → 止损（不等回本）
    └ 连板股（T日收盘涨停）→ 持有至T+2（连板延续）
```

### 2.4 仓位与风控

| 参数 | 值 | 依据 |
|---|---|---|
| 单股仓位 | 20-33%（3-5只等权） | 分散但不过度 |
| 止损 | -3% | T+1 不能再等，硬止损 |
| 止盈 | +5% 盘中冲高 | 不贪婪，锁利 |
| 最大持仓 | 5只 | 仓位集中度上限 |
| 暴风雨天气 | 仓位=0 | 现有硬约束保留 |

## 5. 数据支撑

- a-share-patterns.md 已有 20+ 定律支撑剔除条件（封板时间/换手/连板/缩量等）
- §44 证伪的是"因子连续排序力"，不是"binary 阈值剔除力"——剔除不需要 r>0
- 涨停股 vs 非涨停股的次日溢价差异真实存在（学术文献 + a-share-patterns.md）

## 6. 验收标准

1. `negative_filter.py` 三层剔除产出候选池 + 剔除原因
2. 盘后调度跑剔除流程，存快照供 T 日盘前读
3. T 日竞价+开盘确认逻辑存在（可手工触发）
4. T+1 卖出提醒（止损-3%/止盈+5%/连板持有）
5. 前向测试跑新流程，算 lift（破2x→validated，<2x→标未validated）
