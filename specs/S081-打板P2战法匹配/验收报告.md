## 3. 关键实现决策

### 3.1 K线取数函数（B2）

**实际用**：`limitup_screener.kline_rebuild._get_kline_bars(code, end_date, lookback_days)` 
**未用**：`astock.kline`（直接调）/ `fetch_klines_as_bars` / `kline_resolver.fetch_kline`

**理由**：`_get_kline_bars` 是既有封装（mootdx 主 + tickflow 兜底），返回 `list[KLineBar]`（含 date/open/close/high/low/volume）。复用既有取数逻辑，不新写。plan §0 B2 标注"待核实"，核实后用 `_get_kline_bars`。

### 3.2 S070 R7 门禁（A7）

弱转强接力战法调 `get_snapshots_by_code(code, today)` 取时序 → `compute_derived_features(snaps)` 派生。snapshots 为空（非交易日/未采集）时标 `data_status="missing_s070_r7"`，confidence=0，不输出信号（不报错）。

### 3.3 触发价（A8/B7）

- 弱转强：`entry_price = _round_to_tick_size(pool_item.p)`（昨日涨停价，从涨停池 p 字段）
- 形态反包：`entry_price = _round_to_tick_size(bars[-1].high + 0.01)`（昨日最高价 + 0.01）

### 3.4 StrategyMatcher.match() pool_item 透传缺口（C2）

**缺口**：`strategies/strategy_matcher.py:43` 调 `match_strategies(gene.code, gene)` 不传 pool_item，PRD 战法经 StrategyMatcher 走会因子全 None 不命中。

**处置**：本 spec 约束"只改 limitup_strategy.py + 测试"，不改 strategy_matcher.py。留后续 task（spec §2.1 R2.1 备选 `match_prd_strategies()` 方法或 match() 加 pool_item 参数）。C2 测试改为验证 match_strategies 直接调能命中 + match() 签名向后兼容。

### 3.5 阈值探索性 + config 可配（C4）

PRD 硬阈值（broken_duration_min≥20 / max_drop_pct≥5% / last_lock_time≥14:40 / vol_ratio∈[1.8,3.0] / close_pct<9.5% / max_high≥7% / shadow≥4% / vol_ratio≥1.2 / ma5=Upward）是外部 PRD 拍定值，零数据支撑。

- 注册项 note 标"探索性"
- 阈值从 `config.S081_WEAK_TURN_STRONG` / `config.S081_PATTERN_REVERSAL` 读（getattr，默认值=PRD 拍定值）
- 回测调参门限：financial_rigor --thresholds prd_p2_strategies --window 60d（待 live 数据）
